# Studio 分镜与版本构建工作台改造

## 1. 工作区与交互

- 任务头部支持直接修改标题，不触发任何阶段重建。
- 支持创建、命名、复制、切换构建方案；各方案独立保存分镜结构、参数和依赖选择，共享任务内的历史产物。
- 分镜区采用摘要矩阵：纵向为文字分镜，横向为文本与查询、召回、配音、选片与对齐、分镜渲染。每格显示选用版本、关键结果、依赖提示和操作，完整内容通过展开详情查看。
- 分镜区可整体折叠，随后依次展示成片、产物与调试记录。宽度不足时横向滚动，固定分镜标识与列标题。
- 每格保留单独执行入口。查看历史版本与选为构建输入是两个明确操作；失败记录不能覆盖或隐藏已选成功产物。

## 2. 版本、方案与依赖

- 引入不可变产物版本，记录阶段、分镜身份、执行结果、输入版本、参数快照、文件和诊断信息。每次实际执行形成新版本，失败同样留档。
- 分镜表版本记录镜头数量、身份与顺序；每镜内容独立版本化。增删、合并或重新拆分更新当前方案的分镜表，其他方案保持原结构。
- 召回、配音、选片与对齐、分镜渲染均支持逐镜独立选择成功版本。新执行成功后更新当前方案对应选择；失败保留原选择。
- 上游变化只产生兼容性提示，不清空下游。旧选片和渲染继续展示其原依赖；选用不匹配版本时指出具体冲突。
- 兼容性按实际使用的内容和参数判断：查询变化不影响配音，旁白变化影响配音，选片或音频变化影响对应渲染。
- 每版成片保存实际使用的完整依赖图，界面以可展开的树展示，并允许查看节点详情、复制为新方案。

## 3. 人工控制与构建

- 在选片详情中展示自动选择的锚点、涉及的素材镜头、扩展过程、所选范围和实际使用范围。
- 提供镜头选择模式：按时间排列同一素材的镜头，允许勾选连续镜头、预览并微调边界；禁止跨素材、非连续拼接和穿过隐藏区间。
- 将素材范围与对齐结果分别保存。时长不匹配时，展示裁剪、配音变速、冻结补齐及实际使用范围，用户确认后产生新选片版本。
- 开放声音、召回数量、裁剪范围、变速与补齐方式、原声混音和字幕模式；设置随对应版本保存。重新对齐人工选片保留已选素材范围。
- “构建成片”先列出复用、重建和阻塞清单，用户确认后按依赖执行，不因切换版本自动运行。
- 某节点失败后继续执行其他独立节点，依赖它的节点标为阻塞。必需依赖未齐时不合成新成片；已有成片始终可播放和下载。
- 重试重新计算缺失清单，复用匹配的成功版本；强制重新生成是单独操作。

## 4. 实现与兼容

- 保留现有 Python、文件存储和原生前端架构，扩展版本目录及方案记录，替换“上游重跑即重置下游”的状态逻辑。
- API 增加独立标题编辑、方案管理、版本查询与选择、依赖查询、人工区间预览、构建预检和提交能力。执行请求明确绑定方案及输入版本，媒体 URL 指向确定版本。
- 区分任务、构建执行和节点结果：界面展示运行中、部分完成、失败与阻塞，不使用一个任务失败状态控制所有产物展示。
- 拆分分镜渲染与整片合成。分镜版本保存视频、处理后的音频及帧数；合成时统一计算采样边界和字幕时间轴，避免混用版本后发生漂移。
- 既有任务保留文件和历史，能验证的版本及依赖接入新模型；无法确定的关系标为记录不完整，不虚构依赖。迁移前保留原状态快照。

## 5. 验收与默认约定

- 验证配音重跑失败后，旧配音、选片、分镜视频和成片仍可查看、选择、下载。
- 验证逐镜混选版本、冲突提示、重建清单、部分失败后继续执行及再次续建。
- 验证多方案隔离、分镜结构变化、历史成片恢复为方案，以及依赖树与实际文件一致。
- 验证连续镜头选择、隐藏区间限制、选定范围与实际范围展示，以及对齐后的音画结果。
- 使用真实 ffmpeg 验证混选版本的画面、配音、字幕、时长与完整解码；覆盖非整数帧率。
- 浏览器验收矩阵展开与折叠、版本切换、编辑、预览、构建和历史下载。
- 默认保留现有全局串行执行限制；本轮不增加跨素材拼接、版本删除或自动清理。声音仅开放当前服务支持的能力，不新增音色克隆或情感控制。
