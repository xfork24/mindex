# 全页面 UI 检查与统一修正

## 目标与原则

保留现有绿色视觉风格、功能分区和操作流程，系统检查并修正控件大小、位置、对齐、间距及响应式布局。必要时局部调整布局，使同页同类控件一致、跨页风格协调。

检查后直接修正问题，交付逐项覆盖记录和验证结果。

## 检查范围

- 视频检索：文字、图片、视频查询，人物与素材筛选、结果卡片、详情弹窗。
- 素材管理：素材列表、详情、各处理任务、进度、镜头和片段；编辑、播放、镜头详情、上传、人物配置弹窗。
- 人物库：演员表导入及候选编辑、人物和参考图、视频截图、处理和发布、证据筛选与批量审核；人物编辑、单条及批量审核、关联分镜弹窗。
- 创作：任务创建、方案操作、分镜表格及各阶段展开编辑器、候选选片、时间窗口调整、成片及历史产物；方案创建、复制、恢复、命名、参数、版本详情、构建检查和播放界面。
- 设置：处理设置、全部模型服务及厂商配置分支、检索调参、音色管理；配置档案、音色克隆及登记弹窗。
- 两种生成页面：素材分镜复核、查询相关性复核，包含候选展开区和播放弹窗。

每种界面覆盖正常、空数据、加载、错误、禁用、长文本及大量内容状态；条件显示的字段和操作单独登记检查。

## 修正方式

- 在共享样式中建立统一的尺寸、颜色、边框、圆角、字号和间距规则；清理冲突的页面覆盖，避免不断追加高优先级补丁。
- 普通单行输入框、搜索框、下拉框和普通按钮使用 32px；主要操作按钮使用 40px，紧凑表格操作使用 28px，复选框和单选框使用 16px。同一操作行统一尺寸并垂直居中；同类控件跨页使用相同规则。
- 多选列表、文本域、文件上传和媒体控件按用途单独规范；统一同类样式，不压缩多行内容或媒体操作区。
- 表单统一标签间距和控件排列；同排控件对齐，长标签换行后控件仍保持共同基线。按钮组、分页、工具栏和卡片操作统一间距及对齐。
- 弹窗统一标题、关闭按钮、内容边距及操作区；限制最大高度并允许内部滚动，确保窄屏及长内容下操作可达。
- 保留表格、时间轴和横向列表必要的内部滚动；修正页面整体横向溢出、内容遮挡、文字截断和过度留白。
- 生成的复核页面保持独立可用，采用相同视觉规则；更新模板，使之后生成的页面自动使用修正后的布局。
- 保留已有 DOM 标识、事件和数据接口；不修改公共 API、数据模型或存储结构。更新受影响的静态资源版本。

## 验证与交付

- 建立“页面／界面状态／控件组”覆盖清单，对每组实际控件检查计算样式、尺寸、位置，并人工检查截图。
- 应用页面覆盖中文、英文及 1440、1000、800、540、390、320px 屏宽；生成页面按其现有中文界面检查相同屏宽。
- 同用途控件尺寸和关键样式一致，同排控件中心或基线偏差不超过 1px；所有可见控件、标题和操作区无非预期遮挡、溢出或截断。
- 使用隔离测试库和确定性测试数据进入真实界面，通过现有操作触发弹窗、动态编辑器及错误状态。
- 验证筛选、上传、编辑、保存、取消、分页、折叠、模式切换、播放和时间窗口操作；样式修改不导致输入丢失或事件失效。
- 运行受影响的现有 UI 回归检查；补充覆盖跨页控件一致性、对齐及溢出的浏览器检查。
- 交付检查报告、问题与修正对应清单、代表性前后截图，以及完整覆盖记录；未验证的界面明确列出原因。

## 已确认的默认选择

保留布局并系统修正；按用途统一控件尺寸；包含全部应用页面、弹窗、动态编辑器和两种独立复核页面。测试操作使用隔离数据，保留工作区已有修改。

## 实施期间补充要求

- 所有多行输入文本控件支持用户同时调整高度与宽度。
- 人物筛选的过滤文本框和列表框组合为一个统一控件；列表部分支持通过右下角拖拽调整高度。
- 按控件用途调整合适的默认宽度，并充分考虑页面布局、排列与响应式行为。
- 素材管理页保留顶部“刷新素材”按钮（按后续要求恢复）；中英文切换按钮统一使用“文 / En”SVG 样式图标。
- 创作页的刷新按钮（现有文案“刷新任务”）和设置页的“刷新设置”按钮靠左排列，与导航链接保持一致间距。
- 分镜召回设置增加场景、人物情绪、景别及最短／最长时长筛选；检索页和分镜文本编辑器的素材范围支持可过滤多选列表及列表高度拖拽，兼容已有单素材配置。
- 图片找视频和视频找相似使用一致的控件尺寸及水平排列；文件选择与上传按钮同排对齐，窄屏允许换行。
- 分镜召回候选的演员—角色标记按组合去重，头像使用实际匹配的参考图；排名放在候选画面左上角，不与电影名和时间段混排。
- 选片与对齐阶段不重复显示参考锚点标题、自动选择按钮和召回候选列表；候选选择保留在召回阶段。
- 同行分镜单元格的底部操作对齐；历史版本下拉框与操作按钮同排居中，清理表格按钮的额外上边距。
- 召回候选的电影名和秒数分两行显示，中间不加分隔点。
- 顶部始终按“视频检索、创作、素材管理、人物库、设置”排列；当前页保留并显示选中状态，移除左侧重复的功能标题，保留刷新及语言切换。
