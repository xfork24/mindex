# CLI 数据备份与迁移工具

## 目标与命令

新增 `mindex backup` 命令组，支持完整备份、选择素材备份、空库恢复和已有库合并。导入导出均不调用模型、不重新计算嵌入。

```bash
mindex backup list
mindex backup export /backup/mindex --all
mindex backup export /backup/mindex --source ID1 --source ID2
mindex backup export /backup/mindex --all --include-secrets

mindex backup inspect /backup/mindex
mindex backup import /backup/mindex --all
mindex backup import /backup/mindex --source ID1 --skip-existing
```

- 未指定 `--all` 或 `--source` 时，交互终端显示可搜索、多选的素材列表；非交互环境报错并提示参数用法。
- `inspect` 显示备份版本、素材、索引、文件大小、配置和密钥包含情况。
- 导入导出支持 `--dry-run`，显示最终素材、依赖、冲突和配置处理结果。
- 全局 `--config` 延续现有语义；新增 `--data-dir` 指定恢复位置、`--restore-config` 显式恢复已有库配置。
- 中文帮助、进度和错误信息；`--json` 输出结构化结果。

## 备份内容与格式

新增独立备份模块，集中管理数据库表、文件目录和素材依赖，避免将备份逻辑堆入 CLI。

备份目录包含版本化 `manifest.json`、SQLite 快照、分批向量文件、配置及数据文件；清单记录文件大小、SHA256、素材归属、依赖和原始路径映射。

- 包含原片、所有分镜与缩略图、媒体引用、转写、字幕上传及归档、分析、渠道状态、人工整理、人物特征与证据、历史索引、任务记录及创作产物。
- 全量导出保留数据目录中的其他历史文件和缓存；排除模型权重、可重新下载的模型缓存、锁及未完成临时文件。清单明确记录排除项。
- 选择导出通过素材、分镜、索引成员和任务引用计算依赖闭包；过滤 SQLite 和历史发布快照，不能夹带未选素材的数据。
- 全局人物目录、参考图、音色及系统配置随备份携带。创作任务仅在素材依赖完整时包含；部分备份中无法确定依赖范围的任务排除并报告。
- SQLite 使用 backup API 创建一致快照；Chroma 通过 API 分批导出向量、文档及元数据，恢复时重新建立集合，不直接搬运内部索引文件。
- 默认排除已存 API 密钥；`--include-secrets` 包含设置页保存的密钥。两种模式均不读取环境变量中的密钥，报告所需环境变量名。脱敏处理也覆盖快照中的已知凭据字段，避免原始数据库备份绕过脱敏。

## 恢复、路径与合并规则

**空库恢复：**

- 自动恢复基础 YAML、运行时覆盖、模型配置档案、音色和活动检索组合。
- 默认数据恢复到目标配置的 `data_dir`；全新 clone 可直接恢复为 `data/` 和 `config.local.yaml`。
- 基础 YAML 与数据库覆盖层分别保存，备份命令绕过 CLI 自动覆盖，避免丢失基础配置。
- 携带模型部署清单和本地字体等配置依赖，重定位配置、任务快照中的受管路径；模型目录单独列为待补充项。
- 完整恢复保留既有版本 ID；部分恢复生成新的索引成员清单、索引 ID 和人物发布组合，并维护旧新映射，保留创作任务所依赖的历史版本。

**已有库合并：**

- 默认保留目标系统配置；仅 `--restore-config` 恢复备份配置，执行前预览差异。
- 重复素材默认导致预检失败；`--skip-existing` 跳过并保留目标素材及其全部衍生数据，不支持覆盖替换。
- 共享实体和历史版本只有内容一致才复用；不同内容的同 ID 对象拒绝合并。配置档案、音色及审计记录的本地整数 ID 重新映射，更新关联引用。
- 两端活动索引的模型空间、格式、预处理、模式及适用分析规格一致时，使用既有向量创建联合索引并激活；不兼容则整次导入失败。
- 合并人物检索组合时只使用两端已发布证据，避免将尚未发布的人工修改一并发布。
- 没有活动索引的一端仅导入其数据和历史版本；不为尚未索引的素材自动推理。报告实际可检索素材范围。

## 一致性与失败恢复

首版采用已确认的离线迁移方式：操作前停止 Web 和全部后台写入任务。

- 按现有锁顺序获取管线、素材生命周期、索引及创作锁；锁冲突立即失败。
- 导出写入临时目录，完成校验后重命名为目标目录；目标目录必须不存在，禁止备份到数据目录内部。
- 导入先验证格式、校验和、路径边界、依赖和兼容性，再在同文件系统的暂存目录构建完整结果；合并也在目标库副本上执行。
- 暂存结果通过校验、所有数据库和 Chroma 工作进程退出后，再切换数据及配置。使用持久化操作日志和旧目录支持中断恢复，成功后清理临时副本。
- 拒绝路径穿越及指向目录外的符号链接；必需媒体或向量缺失时失败，不静默降级。
- 迁移遗留的 queued/running 任务标记为 interrupted，保留检查点并允许手动重试。
- 数据库和向量恢复完成后，检查外键、成员、表示、向量数量及媒体引用；模型部署验证记录保留，但不替新部署伪造验证通过状态。

## 验收与文档

新增集成测试，使用真实 SQLite、小规模 Chroma 和现有模拟模型服务验证：

- 完整导出后在不同绝对路径、空配置环境恢复；元数据、配置、向量和检索结果一致。
- 分别在导出和导入阶段选择部分素材；未选素材无残留，历史索引、媒体引用和创作依赖完整。
- 兼容库合并后同时检索两批素材；不兼容、重复或共享对象冲突时目标库保持原状。
- 密钥默认排除、显式包含后恢复；配置档案与音色 ID 重映射正确。
- 覆盖损坏文件、缺失向量、路径攻击、锁占用及切换中断；跨进程重启后向量仍可读取。
- 验证交互选择、脚本参数和 `--dry-run`，运行相关回归及 Ruff。

更新 CLI 文档，并提供“全新 clone → 安装依赖 → 导入备份 → 补充模型文件与密钥 → 启动验证”的恢复流程。操作系统依赖、模型权重和模型服务进程不属于备份；端点配置保留，异机部署可按报告调整。


## 2026-10-21 实际迁移反馈修订

- 部分备份仅携带所选素材关联的演员表与当前/历史证据所需人物、参考图、导入记录，不再无条件携带全局人物目录。全量备份仍保留完整目录。
- 携带活动及历史 v2 索引所需的六样本兼容性基线与已存在的部署验证证据；证据原始字节及服务器路径不重定位，不自动标记新部署验证通过。
- 启动脚本解析共享模型目录的物理路径，避免同机 clone 的 models 软链接导致部署身份漂移。

- 按后续用户要求，导入合并只检查 WeMM 嵌入模型兼容性，不检查分析、ASR 等其他模型；索引格式、预处理及模式仍需兼容，模型来源信息保留在历史快照。

- 项目内基础配置的数据目录、部署清单和字体路径按配置文件保存为相对路径；外置数据目录保持绝对路径，避免项目改名后误用旧目录。
