# Mindex 中英文多语言与热切换

## 实现概要

覆盖视频检索、素材管理、人物库、创作、设置五个 Web 页面及全部系统提示。每页右上角提供“中文 / English”切换按钮，切换立即生效，无需刷新页面或重启服务。

默认中文，使用 `localStorage` 记住语言；页面跳转、刷新及同源多标签页保持一致。素材和用户、模型创作内容保持原文。

## 实现变更

- **共享多语言模块**：采用原生 JavaScript，为现有页面加入统一的翻译字典、参数插值、语言变更事件和文本绑定接口。中英文使用相同翻译键，覆盖标题、导航、表单、占位提示、选项、空状态、弹窗、确认提示、状态、错误、系统日志及无障碍属性。
- **切换入口与布局**：五页页头右侧统一放置语言按钮，标记当前语言，并同步更新页面标题和 `html.lang`。调整页头和组件布局，适应英文长度及窄屏。
- **动态文案**：迁移各页面脚本及共享多选搜索组件中的系统文案；带数量、时间、名称和状态的句子使用完整翻译模板，避免中文片段拼接。内置搜索示例提供英文版本，点击时填入当前语言的示例。
- **原地热切换**：仅更新绑定的文本及属性，不通过刷新页面、重新加载数据或重建整个表单切换语言。保留输入值、筛选、多选搜索、文件、弹窗、展开状态、未保存草稿、焦点、滚动位置及媒体播放状态。异步响应和轮询结果按当前语言显示。
- **后端系统信息**：为页面使用的系统错误、任务进度及日志补充稳定的 `message_key` 和 `message_params`，保留现有文本字段及 HTTP 行为，供前端按当前语言呈现。内置模型角色、厂商预设和说明按稳定标识翻译；历史系统提示通过明确映射兼容，避免对素材文本做全局替换。

## 翻译边界与兼容

- 保持原文：素材名称、文件名、备注、作品/演员/角色名称、对白、字幕正文、素材分析、创作文案、分镜内容及用户命名的档案和音色。
- 完整翻译上述内容周围的标签、说明和操作提示；技术标识、路径、模型 ID、协议名称保持原值。
- 将日志中的系统说明与内容参数分开处理，历史日志同样支持切换；外部服务错误提供中英文系统说明并保留原始诊断信息。
- 不改变素材、索引、模型提示词或生成语言，不增加自动翻译服务；本次不扩展 CLI、开发文档和导出报告。
- 基于当前工作区继续修改，保留已有未提交变更。

## 验证与验收

- 校验中英文键完整一致、插值参数匹配，并扫描 HTML/JavaScript 中遗漏的系统文案；对保留原文的内容明确标注。
- 五页分别验证中文 → 英文 → 中文，覆盖静态界面、动态列表、详情、弹窗、成功/失败提示、任务进度和日志。
- 在填写设置、编辑未保存分镜、选择上传文件、播放视频及运行任务时切换，确认状态保留且后续响应使用当前语言。
- 验证首次默认中文、刷新和跳转保持选择、多标签页同步，以及存储不可用时仍能切换。
- 使用包含中文素材和人物名称的测试数据，确认英文界面保留数据原文；检查长英文文案和窄屏布局。
- 运行受影响的 Python/API 与现有 Node UI 回归测试，补充多语言和热切换测试，并完成五页浏览器检查。
