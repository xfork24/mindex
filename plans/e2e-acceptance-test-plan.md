# 视频素材检索端到端测试计划

日期：2026-10-13。目标：真实视频嵌入 → Chroma 索引 → 中文文字召回 → 网页播放，再加入 ASR、视觉描述和融合检索，比较完整流程效果。

## 基线、约束与执行顺序

- 正式库已有 trailer 的 61 个镜头、61 个精细片段，尚无真实转写、描述或索引。
- 使用用户现有 llama.cpp/GGUF 部署；WeMM 目标为原生 4096 维输出。实际量化类型以 GGUF 权重为准，不把 GGUF 标成 BitsAndBytes INT8。
- 单 GPU 串行运行：WeMM `192.168.1.86:4010` → ASR `:4020` → Qwen `:4040` → WeMM `:4010`。每次切换由助手明确通知，用户启动服务并释放上一模型显存。
- 必要时在 ASR 后独立运行 CPU 强制对齐。TTS `:4030` 不启动，不增加语音查询或在线大模型重排。

## 接口适配与能力检查

增加可切换的 llama.cpp 嵌入/ASR 适配器，保留现有自定义协议。建索引、搜索与模型检查统一使用配置选择的适配器。WeMM 对接 `/v1/embeddings`，实际验证中文文字与原生视频输入。

记录 GGUF 及视觉投影文件哈希、实际量化、llama.cpp build、模板、池化、采样和预处理。标准 llama.cpp 不提供本项目的 `space_id`：部署者提供权重哈希清单，适配器核对服务可观察的运行指纹，明确此信任边界，不把路径或模型别名视为文件哈希。

核对官方 WeMM 嵌入模板和处理方式；文字与视频必须使用同一套配置。出现媒体输入被忽略、常量向量、维度错误、缺少视觉投影或不兼容视频编码时，停止全量建库并提供部署修正要求。不能降级为描述嵌入或平均单帧向量冒充原生视频编码。

ASR 核对音频请求、转写内容及时间戳。纯文本先保存原始转写，再独立强制对齐；对齐条件不具备时暂停对白阶段，不虚构逐字时间。优先使用独立 CPU 环境中的 Qwen3-ForcedAligner-0.6B。

## 分阶段真实测试

| 阶段 | 模型 | 检查与通过条件 |
|---|---|---|
| 固定数据 | 无 | 固定 trailer、配置、切片及整理状态；确认媒体完整，评测期间冻结切分参数 |
| 小样本 | WeMM | 6 个不同场景/动作片段及中文描述；4096 维、非零、有限、单位范数；重复输入稳定，不同视频不返回相同向量 |
| 画面基线 | WeMM | 61 个 moment 建立 visual 索引；向量/元数据一致、重启可读、重跑不重复嵌入；文字/视频查询可播放 |
| 对白 | ASR，必要时 CPU aligner | 30 秒块检查点与时间映射；人工核对至少 10 处对白，记录识别与对齐误差；中断可续跑 |
| 视觉分析 | Qwen | 先 3 个片段，再全部镜头、moment 和场景；检查 JSON、动作情绪依据及连续场景 ≤45 秒 |
| 完整索引 | WeMM | 编码视频、动作场景、情绪镜头和对白；独立 enriched 索引检查通过后发布，保留 visual 回退 |
| 完整验收 | WeMM | 检索、筛选、排序、播放、上下文、后台整理、发布回退和异常恢复 |

复用 model-check、index、transcribe、analyze、check、evaluate；补齐部署探测、小样本能力门槛、独立对齐和可恢复的实验记录。采样目标 4fps、最多 24 帧、单帧最大 262144 像素；实际运行器必须落实，改变参数产生独立实验/空间身份。

## 效果、性能与可靠性

- trailer：20 条中文（8 开发、12 测试），覆盖场景、动作、互动、镜头及对白。助手准备草稿，用户确认标注后冻结测试集；Qwen 输出不能作为独立真值。
- 12 条视频：原片段自检、裁剪、跨切点和分辨率/码率变化，查询不入库。额外 5 条无答案文字只记录误召回，当前没有拒答阈值，不要求返回空集。
- 相同 moment 候选集比较 video_only、description_only、fusion、去对白/去风格消融；报告 Hit@1、Hit@5、MRR@10、nDCG@10、逐查询排名与分路贡献。只在开发集调参。
- 正式验收须增加多个真实来源，包含长镜头、无字幕对白和困难负例，并标注 20 开发 + 40 测试文字。目标 Hit@5 ≥85%、融合 nDCG@10 ≥最佳单路；素材和标注不足时只报告冒烟。
- 记录加载、冷/热推理、全量索引耗时、查询 P50/P95、16GB GPU 显存和 OOM/卸载情况。cold 指首次请求，模型加载时间另计。
- 覆盖模型中断、超时、无效向量、损坏视频、空查询、上传限制、部分建索引恢复、空间身份不符拒绝与回退。
- 后台改名实时显示，父级隐藏继承、恢复保留自身隐藏；收藏不改变排名。质量测试冻结整理状态，功能测试结束恢复。
- 浏览器走通中文输入 → 排名 → 片段 → 上下文 → 对应素材管理。

## 交付与当前执行门槛

本计划已保存到当前目录。实验放在 `data/e2e/` 独立运行目录，保留素材/查询哈希、配置、空间身份、索引、阶段状态、错误、性能与逐查询排名。提供兼容性报告、画面基线、融合比较、浏览器验收和改进清单。

第一步只需要用户启动 WeMM `:4010`。未通过能力门槛不开始全量真实嵌入。ASR、Qwen 在后续指定阶段才启动；最终质量评分需要用户确认的相关性标注和扩充素材。
