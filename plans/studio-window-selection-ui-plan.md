# 召回候选选择与定长窗口选片

## 概要

将逐镜操作统一为：**选择召回候选 → 展示局部连续视频 → 拖动定长窗口 → 预览并确认**。

默认展示同素材的 **前 2 镜＋选中镜头＋后 2 镜**，替换当前列出全部素材镜头、勾选镜头和输入起止时间的人工选片界面。

## 候选与锚点

- 召回候选分别提供“预览”和“设为参考锚点”，明确标记当前选择；保留“自动选择”模式。自动模式沿用现有综合评分，并非固定选择第一个候选。
- 人工锚点按任务、方案和文字分镜独立保存，绑定召回版本与候选 ID。选择只改变构建输入，不自动执行选片、渲染或合成。
- 更换锚点后，新选片使用新候选；已有成功选片和视频继续展示原依赖。此前确认的人工范围不再作为新锚点的输入。
- 切换召回版本后，原人工锚点若来自其他版本，显示具体冲突；重新选片前需重新选择候选或恢复自动模式，不静默替换。
- 没有配音时仍可选择候选；定长窗口等待实际配音生成后启用。

## 定长窗口交互

- 根据候选的真实素材和时间范围定位锚点，展示前两镜、锚点和后两镜的连续时间轴，并标记各镜边界。候选跨多个素材镜头时，其整个区间作为锚点组，前后镜头从区间外计数。
- 默认五镜不足时，先向后、再向前补充最少数量的相邻镜头，标明扩展范围；到素材边界、隐藏区间或不连续处停止。仍不足则提示更换候选，禁止确认，不自动冻结或变速。
- 窗口长度为当前成功配音的实际时长；明确设置配音速度时，使用变速后的时长。没有指定速度时按原速计算，人工窗口不采用自动变速。
- 初始窗口从锚点起点开始，必要时移动至合法边界。窗口可在整个上下文内移动，不要求始终覆盖锚点；只能整体拖动，不能调整长度。
- 提供缩略图时间轴、视频画面、起止时间和时长。支持拖动、点击定位及键盘逐帧微调；长区间支持缩放与横向滚动。
- 拖动仅更新本地位置并定位预览画面，不逐次请求 ffmpeg。直接使用局部视频窗口内的播放键播放当前选区，到结束边界自动停止。提供可选的服务端音画试听；“保存当前窗口”可直接点击，内部自动完成必要校验后才产生新选片版本。
- 草稿按方案、分镜、候选和配音版本隔离。切换详情保留有效草稿；配音或速度变化后重新计算窗口，并使旧预览确认失效。

## 数据与接口

- 在方案中增加逐镜锚点选择，保存自动模式或明确的召回版本、候选引用；将引用纳入选片签名与兼容性检查。
- 增加锚点选择接口和局部选片上下文接口。上下文返回实际锚点、相关镜头边界、合法范围、窗口时长、帧信息和预览资源。
- 扩展现有区间预览与确认接口，绑定上下文、候选、配音版本及方案 revision。服务端自行计算固定长度和结束时间，校验来源、连续性、可见性及依赖是否变化。
- 上下文视频从同一原片连续截取，缓存低清视频和缩略图；缓存标识包含素材身份、范围及可见性。无需拼接不同素材。
- 新选片版本保存原始候选引用、上下文范围、最终选中范围、实际使用范围及音频依赖。人工窗口路径不再把“范围内第一镜”伪装成参考锚点。
- 保留旧区间 API 和历史产物。旧人工版本缺少候选引用时展示已有范围，重新调整需明确选择候选，不猜测历史锚点。

## 验证与约定

- 验证选择非首位候选后，选片确实使用该候选；不同分镜、方案及召回版本不会混用。
- 覆盖默认前 2 后 2、按需扩展、素材首尾、隐藏镜头、断点和可用长度不足。
- 验证拖动全过程长度不变，起止时间与画面一致；配音或速度变化会使旧预览失效。
- 使用真实 ffmpeg 验证确认后的画面、配音、时长和完整解码，覆盖非整数帧率。
- 浏览器验收候选选择、定长拖动、键盘微调、草稿保留、预览确认和历史下载。
- 保留全局串行执行限制；不增加跨素材拼接、自动重建下游或历史版本清理。实施时保留并行任务的修改，不提交或回滚代码。
