# Studio 静态修复与集成验收计划

## 1. 目标与边界

保留 `split → recall/tts → select → render` 工作流，完成已发现的路径越界、旧产物误复用、切片边界、时间轴漂移、原文遗漏和执行竞态修复，再开展真实模型集成测试。

首期验收采用已确认的“技术连续＋人工审核”：保证成片完整、音画字幕同步、人工调整有效。自动叙事连贯优化留待真实素材测试后评估。

沿用原生前端、文件状态机、SQLite 素材库与 ffmpeg，不新增任务数据库或队列依赖。

## 2. 工作流、检查点与兼容

**执行生命周期**

- 所有执行、编辑、删除统一采用“进程内 guard → 文件锁”的顺序；跨线程交接的 FileLock 显式设置 `thread_local=False`。
- 持锁后重新读取任务、检查依赖，并落盘首步 `running`，随后启动线程并返回 202。拆开“开始步骤”与“执行步骤体”，避免重复开始。
- 增加任务级 `execution`，包含状态、当前步骤及剩余步骤；连跑期间持续保持 `running`，前端据此轮询。
- 线程启动失败、步骤失败、服务中断都记录终态和 attempt，保证释放锁；中断恢复同时处理执行状态与步骤状态。

**检查点有效性**

每个检查点记录输入指纹、输出路径、内容哈希及必要的媒体信息：

| 产物 | 指纹覆盖内容 |
|---|---|
| 拆分镜 | 原文、模型配置、提示词与校验版本 |
| 召回候选 | 查询、固定索引、粒度、数量、搜索配置及素材可见性 |
| 配音 | 文本、声音、模型配置与音频格式 |
| 选片 | 分镜顺序、候选、配音时长、选片配置及素材可见性 |
| 渲染 | 原片身份、实际区间、配音内容、变速、音轨及输出参数 |

- `resume` 仅复用指纹一致、文件完整且校验通过的检查点。
- `force` 绕过指定检查点；未指定分镜仍按 resume 处理，缺失或失效的输入正常补齐。
- 每次执行采用当前有效配置，保存完整且去除凭据的 attempt 快照；任务创建快照仅用于追溯。
- 查询变更仅作废 recall/select/render；文本变更仅作废 tts/select/render；增删镜作废相关分支；仅调整顺序作废 select/render；标题变更不影响媒体。

**历史与迁移**

- 新输出写入 attempt 独立目录，由当前产物清单引用；失败重试可复用先前有效检查点，历史文件不覆盖、不做孤儿删除。
- 兼容读取旧任务及下载旧产物。旧缓存缺少可信指纹时，首次续跑按未验证处理，重建对应步骤及其依赖。
- 保留现有逻辑下载 URL，由清单解析实际版本；旧成片标记为历史版本，不冒充当前文案的有效成片。

## 3. 文案、选片与媒体合成

**输入与拆分镜**

- 分镜 ID 限制为 `[A-Za-z0-9][A-Za-z0-9_-]{0,39}`；所有产物路径解析后必须位于任务目录内。
- 自动拆分按顺序完整覆盖原文，比较时仅忽略空白，不忽略标点；遗漏、重复、乱序、改写及数量超限进入模型修正重试。
- 人工编辑允许有意改稿，重新计算并展示覆盖差异。
- 时间、时长和权重拒绝非有限数值；候选选择与显式区间二选一，拒绝混合参数。

**选片与区间**

- 补齐 `extended+padded`、`extended+trimmed` 枚举。
- 自动区间钳制到原片范围；人工区间必须满足有效长度，片尾空区间和倒置区间返回 422，超出片尾的 end 钳制并提示。
- 视频足够长时优先裁剪并保持配音原速；不足时采用同源上下文延长、最多配置上限的配音加速、冻结末帧兜底。
- 上下文延长遇隐藏片段即停止，不跳过隐藏区间继续延长；选片和渲染前重新检查可见性。
- 候选预览复用素材管理的媒体及缩略图接口，避免依赖当前活动索引。最终延长区间另提供渲染预览，便于人工核对。

**共同时间基准**

- 先处理配音为 48kHz PCM，读取实际采样数，再确定每镜输出帧数。
- 每镜帧数向上取整；音频按累计帧边界换算采样边界，仅补齐，不裁掉配音。将实际帧数、采样边界和字幕时间保存为渲染清单。
- 视频先严格裁到所选原片区间，再冻结末帧并输出规定帧数，禁止补时读取后续画面。
- 视频、音频、SRT 和 WebVTT 都使用该清单；最终 mux 不依赖 `-shortest` 掩盖时长差。
- ducking 的背景音补齐至事件长度，并避免混音默认归一化造成配音音量突变。
- 成片通过轨道、时长和完整解码检查后发布；失败保留上一版成片。烧录路径检查滤镜及显式字体文件，中文字形效果在可用环境中做视觉验收。

## 4. API、页面与产物下载

| 接口 | 最终行为 |
|---|---|
| `POST /jobs/{id}/steps/{step}` | 可选请求体 `{mode:"resume"\|"force", shot_ids?:[...]}`；无请求体默认 resume |
| `POST /jobs/{id}/run` | 继续未完成步骤，采用 resume；服务不可用时保留产物并停止 |
| `GET /jobs/{id}` | 增加 execution、产物版本及有效性信息，返回完整候选池 |
| `GET /jobs/{id}/artifacts` | 列出当前及历史产物，包含步骤、attempt、大小和下载 URL |
| `GET /jobs/{id}/archive` | 空闲时导出任务 ZIP；执行中返回 409，避免不一致快照 |

- `shot_ids` 仅用于 force 模式下的 recall、tts、render；未知、重复或空列表返回 422。split/select 只支持整步操作。
- 页面分别提供“继续/重试”和“重新生成”，支持逐镜重做；执行期间禁用编辑。
- 完整候选随详情返回，删除现有异步候选缓存链路；详情请求绑定任务与请求版本，丢弃过期响应。
- 时间线编辑保留未修改事件，支持候选换选及显式区间；轮询不覆盖未保存草稿，提供取消编辑。
- 软字幕播放器加载 WebVTT；成片 URL 带版本，避免浏览器播放旧缓存。
- attempt 保存模型请求与原始响应、校验反馈、实际配置、ffmpeg 命令及诊断、产物清单；不保存认证头或密钥。
- ZIP 包含任务内中间产物、历史和诊断，排除临时文件及导出包本身；原始素材以身份和路径引用，不重复打包。

## 5. 实施顺序与验收

依次完成四组改动，每组补对应回归测试：

1. **状态与存储基础**：路径安全、执行生命周期、attempt 留存、指纹及旧任务兼容。
2. **步骤正确性**：原文覆盖、精确失效、续跑/强制重做、区间与隐藏素材处理。
3. **媒体合成**：正确冻结帧、共同时间基准、完整配音、字幕与原子发布。
4. **页面与交付**：编辑闭环、预览、下载列表、ZIP，并同步更新方案及运行时文档。

静态修复完成标准：

- 编辑文本后实际配音变化；换选后实际画面变化；有效检查点保持复用。
- 指定分镜强制重做、部分失败续跑、跨任务切换、锁冲突及重启恢复正确。
- 真实 ffmpeg 覆盖非整帧时长、片尾、冻结帧、不同帧率与 60 镜时间线；边界误差不超过一输出帧，没有累计漂移或尾部配音丢失。
- 全仓库 pytest、Ruff、JavaScript 语法检查通过；完成无模型浏览器操作闭环。环境缺失的烧录验收明确记录为待验证。

随后按单 GPU 条件依次部署：**拆分镜 Qwen → Qwen3-TTS → 索引对应嵌入模型**，每阶段先验证实际接口与模型身份，再运行任务步骤；最后在本地完成选片、渲染和人工质量验收。真实模型名称、TTS 端点与音色以部署探测结果为准，不根据当前默认配置推定兼容。
