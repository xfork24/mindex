# 以 shot 为唯一业务媒体来源的改造与数据迁移

## 目标与边界

shot 就绪后，系统所有视频、音频和截图业务均从 shot 获取媒体：moment 引用镜头内区间，scene 和跨镜区间引用多个 shot，并按需串播或拼接。禁止业务流程隐式回退读取原片。

原片按已确认选择保留为归档。只有首次导入、探测、分镜检测、shot 生成，以及显式修复 shot 时允许读取原片；归档完整性校验属于独立维护功能。

保留既有 segment ID、绝对时间边界、分析、人物证据、向量、索引快照及发布状态。不重新索引，不强制重新分析。此次删除目标仍为可替代的 moment / scene 文件。

## 统一媒体与时间轴

新增统一的 shot 媒体服务，提供以下能力，业务代码不再自行解析 `sources.path`：

- 根据素材绝对区间生成有序 shot 引用；每项包含 shot ID、镜头内起止时间、逻辑偏移。
- 单时刻截图、区间抽帧、音频提取、完整 MP4 生成和可用性检查。
- 素材绝对时间、shot 局部时间、片段逻辑时间三者转换；内部边界采用左闭右开，素材终点按最后可解码帧处理。
- 校验同源、顺序和完整覆盖；时间计算容差 1 微秒，媒体实际边界允许一帧误差。缺失、损坏或覆盖不完整时明确失败，不读取原片补救。

新增以旧媒体 `path` 为键的引用表，保留旧路径和索引快照。moment 使用父镜头；scene 按时间求交生成引用；整部素材也通过相同机制描述。

实体生成规则：

- 完整单 shot 直接复用；局部区间裁剪；跨 shot 区间裁剪后拼接。
- 重置各段时间戳，统一尺寸、像素格式和音频格式，输出 H.264/AAC；混合有声与无声区间补静音。
- 图像直接从对应 shot 解码；音频按 shot 区间解码并拼接为目标 PCM，避免先生成中间 MP4。
- 允许重编码带来的字节与画质差异；不把新生成媒体视为既有分析或向量失效的理由。
- 完整文件进入独立缓存，键绑定 shot 文件指纹、引用和实现版本。使用文件锁、临时文件及原子替换；缓存默认最近使用保留 7 天、容量上限 5 GiB，使用中的文件禁止淘汰。

## 全系统依赖替换

### 播放、截图与人物库

- 检索、后台和 Studio 候选预览使用播放清单；统一播放器提供片段进度条、拖动、倍速、重播和全屏。
- 两个视频元素交替播放并预加载下一 shot；跨镜尽量平滑，不承诺逐帧无缝。普通预览不生成完整 MP4。
- 人物库“从原片选取参考”改为“从素材选取参考”：整素材 shot 时间轴播放，截图请求仍提交素材 ID 和绝对时间，服务端定位 shot 后截图并裁剪。
- 人物特征提取改为逐 shot 输入，返回局部时间后转换为素材绝对时间；保持现有采样时刻规则和证据坐标约定。
- 保留已有特征、匹配结果、确认记录和发布数据。新提取结果使用新的媒体实现版本键，未命中时从 shot 提取，不触发全库复算。

### 转写、字幕与片段详情

- ASR 的 30 秒分块、强制对齐和对白重跑改从 shot 提取音频，维持既有绝对时间、分块编号及已完成检查点。
- 内嵌字幕必须在原片解除业务依赖前归档：保存轨道元数据、文本字幕和可独立读取的原始字幕轨；位图字幕及所需字体附件也保留。
- 字幕归档保持原轨道标识、语言、默认标志和绝对时间。对白字幕选择、提取、镜头详情和后台元数据统一读取归档；已有外部字幕上传流程继续工作。
- 新导入在准备阶段完成字幕归档。迁移时归档失败的素材不标记为“原片依赖已解除”，不得悄然丢弃轨道。

### Studio、上下文及其他读取入口

- 上下文预览、时间窗缩略图、Studio 选区预览、最终裁剪、环境音与 ducking 全部通过统一媒体服务读取 shot。
- Studio 对外仍保存素材绝对区间；进入渲染前转换为区间局部时间，保留现有配音、冻结帧及字幕对齐规则。
- 已完成 Studio 成片及检查点保持有效；后续重渲染使用新增媒体实现版本指纹，避免误用依赖旧媒体的中间缓存。
- 原有素材媒体 URL 和片段 `media_url` 保持返回完整文件的契约，从 shot 按需生成；网页整素材播放改用清单，避免为选参考而拼接整片。
- 离线报告、评测样本生成、视频导出及业务索引检查统一走媒体服务。索引检查验证 shot 与字幕依赖，不强制要求归档原片存在。
- 原始哈希校验仅作为明确的归档维护检查；历史按字节固定的验证产物保留，不以新拼接文件冒充旧产物。

## 存量迁移与恢复

新增 `mindex clips migrate`，默认只读预览，支持 `--source`、`--apply`、`--verify`，重复执行可续跑。

1. **先部署兼容能力。** 旧实体优先读取，缺失时使用 shot 引用；新生成 moment / scene 仅登记引用，缩略图从 shot 获取。
2. **盘点与备份。** 扫描所有 segment、全部索引快照、shot、字幕及固定哈希引用；使用 SQLite backup API 备份数据库，按 inode 计算空间，输出逐素材计划。
3. **归档字幕、登记引用。** 在现有管线与索引锁下按素材提交；保存迁移版本、依赖摘要和逐文件状态。无效引用、shot 不完整或字幕归档失败均保留旧文件并报告。
4. **验证独立运行。** 对每个素材验证字幕归档、截图、音频提取和代表性区间重建；对所有引用执行覆盖及依赖检查。
5. **删除冗余实体。** 只有引用提交并验证成功才删除对应 moment / scene MP4；固定哈希文件保留。操作逐文件记录，中断后续跑。
6. **完成业务验收。** 临时使原片对应用不可访问，验证全系统业务；随后恢复归档访问。对比迁移前后分析、人物数据、向量及索引快照摘要，输出实际释放空间。

存量迁移安排维护窗口，暂停服务与写任务；完成后重启验收。预计最多释放约 6.08 GiB，扣除需保留文件及新缓存后报告实际值。

新增 `mindex clips materialize --all`，仅从 shot 恢复旧路径下的实体切片，支持旧程序回退；不保证恢复旧文件的逐字节内容。既有未提交代码改动予以保留。

## 测试与验收标准

- 覆盖整镜、局部、跨镜、非关键帧边界、短镜头、可变帧率、无声及混合音轨，验证画面顺序、音画同步和时间转换。
- 验证人物参考选择、bbox 截图、人物采样绝对时间、历史证据定位，以及已有确认结果无需重算。
- 验证 ASR/对齐续跑、文本与位图字幕归档、轨道选择及镜头详情，已有转写结果无需重跑。
- 验证 Studio 选区、跨镜渲染、环境音、ducking、冻结帧和字幕时间轴；既有成片可继续访问。
- 验证检索、后台、历史索引切换、上下文播放、下载及 HTTP Range/HEAD。
- 验证迁移预览不改数据、硬链接统计、中断续跑、重复执行、缺失 shot、并发生成和缓存保护。
- 增加业务路径“禁止读取归档原片”的自动化检查，并在原片不可访问时执行端到端验收。
- 最终要求：既有分析、人物及索引数据保持不变；所有准备完成的素材业务只依赖 shot 与字幕归档；重跑 prepare、analyze 和索引检查不会恢复全量冗余实体。

交付包括实现、测试结果、数据库备份位置、原片依赖审计清单和实际数据迁移报告。


## 执行补充约束（用户于 2026-10-19 确认）

本轮不执行存量媒体的物理删除或缓存淘汰。完成实现、测试、备份、引用登记及独立运行验证后，先提交执行报告、待删除文件与空间清单、用户验收方案。只有用户明确验收通过并授权后，才进入物理删除阶段。`mindex clips migrate --apply --verify` 仅登记和验证，保留旧实体。

## 分镜首帧校正补充授权（2026-10-19）

用户明确要求“现在校正分镜首帧问题”。允许基于原片实际帧 PTS 校正已确认偏差的存量分镜边界，保留 segment ID，同步关联 moment/scene 和索引快照的区间元数据，保留旧媒体与数据库/分镜计划备份。人物证据的原片绝对采样时间、确认结果与特征向量保持不变，不做全库重新分析或索引重建。此项授权不包含物理删除。
