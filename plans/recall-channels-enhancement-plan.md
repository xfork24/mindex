# 三渠道独立处理与混合召回改造

## 目标与已确定选择

将视频画面、对白文本、LLM 分析拆成三个独立渠道，各自处理、嵌入、缓存和召回，共享素材 ID、片段 ID 和原片时间轴。

- 首版复用当前 WeMM，各渠道向量分别保存和检索。
- 对白优先读取完整中文字幕；没有可用字幕时使用已启用的 MiniMax-ASR-1.0。
- 本次不运行多模态 LLM 分析，但解除其对对白的强制依赖，保留未来接入能力。
- 网页与 CLI 均支持处理；检查通过后自动发布，旧版本可回退。
- 人物名字先支持“对白提及”，不推断画面人物身份。

## 渠道、索引与召回

- 每个渠道独立记录处理状态、内容版本、模型身份和输入指纹。一个渠道缺失、失败或配置改变，不使其他渠道失效。模型客户端按需初始化。
- 建库增加默认 `auto` 模式，使用当前已完成的渠道数据；支持显式指定渠道。保留 `visual` 视频模式和既有命令兼容入口，移除默认流程对完整 LLM 分析、语义场景分组的要求。
- 新索引按实际表示校验完整性，允许片段只拥有部分渠道；无内容不生成占位向量。已有分析结果可独立纳入，未来分析可以使用可选对白，并记录实际输入版本。
- 增量构建新索引，保留活动版本中的其他素材和渠道。按原片、时间窗口、预处理、文本内容及嵌入模型身份匹配，复制兼容向量，避免重复推理。
- 保持索引快照不可变；构建完成后检查并原子切换活动版本。处理或发布失败时继续提供旧版本。
- 新版文字检索分别召回三个渠道。对白、分析渠道各自融合语义向量和 BM25，内部默认等权；三个渠道再按默认 `1:1:1` 加权 RRF 融合，缺失渠道跳过。分析渠道将结构化描述与风格字段组织为独立文本，不混入对白原文。
- 搜索结果提供渠道、命中文本、证据时间和排名明细；保留同源时间去重、隐藏与筛选行为。图片／视频查询继续检索画面渠道。
- 保持旧版索引可查询、可回退；旧版使用原有排名配置，新版设置页提供三个渠道的权重。
- 若查询嵌入服务不可用，有可用词法索引时返回明确标注的降级结果；没有可用召回路径时明确报错。

## 对白获取与时间定位

- 对旧素材重新探测字幕轨道，不要求重新导入、分镜或切片。
- 默认按“中文完整文本字幕 → 默认完整文本字幕 → 其他完整文本字幕”选择一条；排除仅含零星提示的 forced 字幕，允许指定轨道。
- 使用 FFmpeg 提取文本字幕，清除样式并保留正文、语言、轨道来源和原片时间。位图字幕、烧录字幕不做 OCR；无可用文本字幕、提取失败或结果为空时回退 ASR，并显示原因。
- MiniMax 请求 `verbose_json` 与 `timestamp_level=word`，解析并保存原始响应、时间戳和说话人编号。编号不作为人物姓名。非空文本缺少有效时间戳时标记失败，不伪造定位。
- ASR 沿用 30 秒分块，各块前后增加最多 1 秒上下文；按词时间中点归属原始分块，避免重复收录。保存分块检查点，重试只处理未完成部分。
- 保留词级时间，同时按标点及停顿组织对白文本；将与片段时间相交的对白关联到对应片段，不自动扩散到整个场景。
- 字幕与 ASR 使用不同内容指纹；切换 ASR 模型不使已提取字幕失效。静音、无音轨和无对白显示为空内容状态，不生成文本向量。
- 兼容旧的纯文本 ASR 和手动对齐命令；MiniMax 新流程直接使用服务时间戳，不依赖本地 ForcedAligner。

## 网页、CLI 与任务接口

- 素材详情显示三个渠道的处理状态、已发布覆盖率、对白来源、字幕轨道、任务进度及错误；区分“处理完成”和“已进入检索”。
- 网页提供“补充对白”、轨道选择和失败重试；LLM 渠道显示“未处理”，本次不触发分析。
- 新增 `mindex enrich-dialogue [SOURCE]`：省略素材时批量处理，默认断点续跑并自动发布；支持 `--subtitle-stream` 指定轨道及 `--no-publish` 仅生成数据。底层转写与建库仍可分别执行。
- 新增启动对白任务、查询任务状态、重试任务的管理 API；任务状态持久化，HTTP 请求立即返回任务 ID。
- 后台处理复用管线文件锁，与 CLI、删除操作互斥；任务启动时冻结生效配置。重启后将未完成任务标记为中断，由重试继续，避免自动重复提交 ASR。
- 文字搜索增加可选 `channels` 参数，默认使用全部可用渠道；状态接口增加渠道覆盖情况。现有搜索调用无需修改。
- 将新增任务、渠道元数据和缓存纳入素材删除与版本管理。

## 验证与实际落地

- 自动化验证渠道任意组合、LLM／ASR 未配置或不可用、空对白、部分分析完成时均能按已有信息建库和检索。
- 用真实 FFmpeg 构造中文／多语言字幕素材，验证轨道优先级、样式清理、时间偏移、指定轨道及 ASR 回退。
- 验证 MiniMax 时间戳、分块边界、静音、无效响应、限流重试和中断恢复；确认字幕素材不调用 ASR。
- 验证增量建库不重新调用已有视频嵌入，保留其他素材、隐藏设置和分析渠道；失败不影响活动索引，回退可用。
- 验证网页启动、刷新后恢复进度、重试、发布结果，以及 CLI／网页共用运行时配置。
- 扩展评测，分别比较纯视频、纯对白、视频＋对白及可用分析渠道；关闭渠道时同时排除其 BM25 文本，防止信息泄漏。
- 先在当前电影中选取约 3 分钟有对白区间，验证已配置 MiniMax 端点、词级时间戳、原片定位和真实检索。通过后补齐整部电影，对现有 2,336 个视频向量执行兼容性核对并复用。
- 全程不调用多模态 LLM。新版本检查通过后自动发布，记录处理耗时、复用数量、渠道覆盖率和回退版本。
- 使用人物提及、准确台词、近义表达及视觉查询检查改善和退步；人工确认相关片段前，仅报告工程验证结果，不宣称准确率提升。

## 执行顺序补充（用户后续指定）

- 先完成所有对白提取与 ASR 工作，再执行真实嵌入。
- 开始真实嵌入前通知用户，等待用户部署模型后执行。
- ASR 阶段使用 `--no-publish`，不提前触发嵌入或发布。
