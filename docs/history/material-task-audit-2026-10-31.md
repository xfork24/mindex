| --- | --- |
| 导入、分镜与切片 | 原片按内容去重；已保存计划、有效切片与缩略图复用，只补缺失/空文件。 |
| 对白、ASR、对齐 | 完整结果默认复用；中断分块按实际范围及上下文续跑，保留各块真实来源；`--force` 才主动忽略相应检查点。 |
| LLM 与场景 | 相同区间沿用结果及场景 ID，分组检查点可跨配置档案续跑；当前场景按最新计划发布，历史快照保留。 |
| 人物 | 特征按实际区间、空间和采样规则复用，ID 改变不触发推理；部分镜头采样使用物理切片偏移。 |

| 依赖检查 | 按源复用分镜/字幕检查；发布准备与最终一致性检查共用持久探测缓存，以文件路径、大小、纳秒 mtime 失效，不重复启动 ffprobe。 |

## 任务互斥与取消

- 索引写锁继续串行，拿到锁后才读取活动索引，避免并发发布丢失其他素材/渠道的更新。
- 等待索引锁时定期调用取消检查，不必等上一个发布结束；大批媒体准备和向量复制也保留取消检查。
- 素材与工作类别分别持有任务锁，删除素材与全部处理互斥；恢复逻辑尊重仍存活任务的租约。
- `enforce_gpu_lock` 仍是显式 GPU 独占策略；关闭时各任务可按作用域并行，不改变用户选择。
- 清理仍按规范锁顺序执行，取不到处理锁时退出；不强行停止在线任务或删除锁文件。

## 缓存与垃圾回收

- 处理检查点改用唯一临时文件原子写入，异常时立即回收临时文件；独立对齐 worker 也增加失败清理。
- `TemporaryDirectory` 管理的音视频中间文件在成功、失败或取消退出时回收。
- 清理识别素材处理树内的未完成写入；执行前重读媒体/源文件引用，保护正常输入与 Studio 归档。
- 在线检索的 `query-*` 临时目录不持管线锁，另加 `temp_grace_hours` 宽限期并在删除前复核，
  保护刚建立的空目录和预览后重新使用的目录。
- 缓存淘汰使用最近访问/修改时间，执行时持文件租约再次检查；保留锁 inode。播放结束及断线均释放租约。
- 播放合成缓存的容量回收节流为最多每分钟一次，跳过使用中的文件。
- 人物帧保留全部现存发布快照引用、未确认镜头证据和覆盖特征中的帧；迁移不重写不可变发布快照。
- 索引保留集包含 Studio 引用、检索组合及可续跑素材任务；引用无法解析时保守保留。执行时再检查，
  避免预览后新增的引用被删除。
- 排队/运行任务的索引持续受保护；已失败、中断或取消的任务按最近更新时间和 building 保留期
  保护检查点，历史任务记录不会永久阻止过期索引回收。
- 人物上传图与声音文件增加上传宽限期，并在执行删除前再次核对引用。
