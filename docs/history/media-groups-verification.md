# 素材组与音乐组验证（2026-10-31）

用户流程：素材管理的「管理」Tab → 组 REST → SQLite 组与成员关系 → 素材/音乐详情和检索筛选；任务、Agent 与 MCP 使用同一事实与有效范围。所有测试使用隔离数据与确定性模型，不读取或改动用户媒体库，不代表真实模型的语义质量评测。

## 实现边界

- 第 9 次元数据迁移增加组与成员表；名称按类型去首尾空白后唯一，成员去重、批量事务校验、删除媒体时清理关系。历史 `user_version=0` 副本中已有组表也能升级。
- 多组成员取并集，再与手动素材、任务和其他筛选取交集。未选择组不限；空组无候选；已删除或类型不符的组明确报错。
- 任务保存组 ID；详情返回当前有效范围和错误。召回签名包含被引用组的当前成员与失效状态，组修改不写工作台、选片、曲目或构建产物。
- 管理页支持两类组、成员分页、库内搜索和批量成员操作；素材/音乐详情可多选归属。检索四入口、任务创建与范围编辑、分镜召回、音乐列表与推荐支持组筛选。
- 增加 10 个 Agent/MCP 工具，并扩展原检索、任务、分镜与音乐工具。组工具复用 `library`，任务范围工具归入 `studio_detail`，保持主创作工具域的数量约束。页面上下文与定位携带组信息。
- 完整备份保留空组；部分备份裁剪成员及无导出成员的组，组范围明确的任务可随素材导出。音乐文件随全局曲库携带。合并同名但成员不同的组时保留独立组，避免扩大导入任务范围。
