## 实现与问题对应

| 原问题／新增要求 | 修正 | 验证证据 |
|---|---|---|
| 普通按钮、输入、选择框使用各页不同的 padding 和尺寸 | 共享 `--control-size`、字号、边框及圆角；普通 32px、主操作 40px、紧凑操作 28px、复选框／单选框 16px；页面覆盖仅保留用途差异 | 控件级计算样式；115 项相关测试 |
| 同排标签换行、按钮与下拉错位 | 表单容器底部对齐、操作行居中、8px 控件间距；方案选择使用水平标签布局 | 所检查同高同排控件最大中心偏差 0px |
| 多行文本仅能纵向调整 | 全部 textarea 使用 `resize:both`，保留默认宽度和用途所需高度；最大宽度受当前容器限制 | 真实鼠标拖动检索文本框，验证宽高变化与内容保留；逐控件检查 `resize` |
| 人物搜索过滤输入与多选列表是两个独立控件 | 共享 `multiselect.js` 将原输入和 select 保留在同一边框内；列表容器右下角纵向拖拽，最小 72px、默认 112px | 鼠标拉高后搜索、选择、清除和重新填充选项均保留列表高度；国际化节点保留回归 |
| 人物过滤默认宽度过窄 | 多选控件默认 260px，检索方式 230px、多人关系 220px；人物库筛选弹性分栏，窄屏单列；文本编辑器依用途弹性排列 | 中文／英文六种屏宽；长名称与大量选项；选项完整文字保留 title |
| 弹窗宽度、边距、关闭按钮不统一，长内容操作不易到达 | 共享弹窗 24px／窄屏 16px 内边距、32px 关闭按钮、标题避让；限制 `100dvh` 内高度并内部滚动 | 所有登记弹窗检查可视范围和横向溢出；滚动至末尾控件验证可达 |
| 英文候选按钮挤在窄卡片内截断 | 创作候选卡片最小默认宽度 220px，卡内动作分别占行，使用 32px 控件 | 候选编辑区、时间窗口、播放和选片各屏宽检查 |
| 页面栅格在窄屏有固定最小宽度 | 栅格使用 `minmax(min(...,100%),1fr)`；工具栏和卡片动作允许换行；表格、时间轴及列表保持内部滚动 | 320–1440px 整页与弹窗无横向溢出；素材滚动回归 |
| 两种导出复核页与应用视觉分离、相关性页缺少 viewport | 将共享样式与 `review.css` 嵌入两个生产模板，增加 viewport，移除播放器固定内联宽度 | 新增离线导出测试；真实导出文件分页、候选展开、播放、错误提示 |
| 删除素材管理“刷新素材”按钮 | 移除该 DOM 及其事件绑定；其他素材操作和轮询继续使用原流程 | DOM 缺失断言；素材上传、任务、字幕、滚动回归 |
| 文／En SVG 样式语言切换 | 五页使用 22px SVG 字形和 32px 按钮，保留 `data-language`、`aria-pressed` 和中文／English 可访问名称 | 国际化浏览器回归，包括输入、焦点、文件、播放状态及跨标签页同步 |

## 覆盖与结果

Chromium 共检查 **1,458 个页面／状态／语言／屏宽案例、85,938 次实际控件测量、125 个控件组**。五个应用页面使用中文和英文；两个导出页使用现有中文。屏宽均为 1440、1000、800、540、390、320px。计算样式检查覆盖尺寸、字体、边框、圆角、padding、resize、位置、禁用状态、同排偏差、页面／弹窗溢出、关闭按钮与标题重叠以及按钮文字遮挡。最终记录中布局违规与浏览器脚本错误均为 0。

逐组记录见 [ui-layout-coverage.md](ui-layout-coverage.md)，全部案例摘要见 [coverage.csv](../artifacts/ui-layout/after/coverage.csv)，每个控件的测量明细见 [coverage.json](../artifacts/ui-layout/after/coverage.json)。测量数量包括相同控件在不同语言和屏宽下的重复测量，不是独立控件数量。

正常、空数据、长文本和大量内容进入真实页面。检索加载和 503 错误通过延迟实际 fetch 返回触发；模型档案列表、已存密钥提示、连接失败和音色目录降级采用确定性接口响应，仍由原页面渲染和原事件触发。处理运行、等待、失败和进度状态另由现有浏览器回归检查覆盖。以上是按界面登记的实际案例，不声称覆盖每个界面所有状态的完整组合。

实际操作覆盖：查询与筛选、双向文本框拖动、组合列表拖高与搜索、清除、上传失败恢复、字幕选择、保存草稿、人物新增、编辑取消、分页、分区切换、角色展开、单条／批量审核弹窗、视频截图、方案新建／复制／命名／参数弹窗、五列生成、文本／图片／视频召回编辑器、历史版本详情、时间窗口键盘移动与保存、候选播放、成片构建、成片历史及恢复方案弹窗、参数分支、音色登记／上传／URL 模式、语言切换。

未完成的验证明确如下：

- 所有页面的每个错误／加载／空数据状态没有逐一组合六屏宽和两语言；覆盖文件列出了实际测过的组合。未列出的状态依赖共享样式推断，不能当作已验证。
- 厂商连接、模型真实生成、自动演员表解析及真实音色克隆没有发起外部调用；UI 分支与服务失败提示使用工程数据。音色注册和配置保存的后端由现有测试覆盖。

- 仅 Chromium 桌面引擎的响应式视口；没有验证 Safari、Firefox、手机系统原生 select 或触屏的 resize 把手。
- 全页截图可能捕获超长页面，动态表格仍限制自身高度；长编辑器和时间轴内容通过表格内部纵向滚动到达。

## 复现

在临时目录启动服务（每个新数据目录只执行一次 seed，避免重复工程身份）：

```sh
.venv/bin/python tests/serve_fixture.py --data-dir /tmp/mindex-layout-new --port 18329
.venv/bin/python tests/seed_layout_fixture.py --data-dir /tmp/mindex-layout-new
.venv/bin/python -m http.server 18331 --bind 127.0.0.1 --directory /tmp
MINDEX_LAYOUT_DATA=/tmp/mindex-layout-new MINDEX_LAYOUT_URL=http://127.0.0.1:18329 MINDEX_PLAYWRIGHT_MODULE=/path/to/playwright node tests/ui_layout_browser.cjs
```

复核页面 URL 从隔离 fixture 文件自动读取；`MINDEX_LAYOUT_REVIEW_URL` 可设置导出文件 HTTP 服务地址。`MINDEX_LAYOUT_RESUME=1` 可跳过覆盖记录中已有的布局组，继续执行操作；完整验收不要设置此参数。
