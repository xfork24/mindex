# 召回筛选和素材多选验收

日期：2026-10-19。

## 修改

- 分镜文本编辑器的召回设置增加场景、人物情绪、景别、最短及最长时长；文字、图片和视频召回共用这些筛选。新增值保存到原有分镜召回配置，取消修改恢复已保存值。
- 检索页及分镜编辑器的素材范围改为共享过滤多选列表，支持搜索、全部选择和右下角调整列表高度。不选素材时搜索全部库；过滤列表不会取消已选项。检索页刷新和语言切换保留选项。
- 检索页素材范围默认占 320px，较窄桌面占 260px，其他字段分两列；窄屏单列。分镜召回普通字段默认 240px，素材筛选分组采用三列／两列／单列布局。
- 图片和视频检索的上传区使用相同排列、提示行和文件框宽度，预览统一居中。分镜文件选择框与上传按钮在独立操作行底部对齐，均为 40px，窄屏允许换行；其他单行字段仍为 32px。
- 查询接口新增可选 `filters.source_ids`，兼容原 `source_id`。非空多选优先，空列表回退单素材字段；两者均未设置时搜索全部库。多素材取并集，再与场景、情绪、景别和时长取交集。无需数据库迁移。
- 召回签名对素材列表去重并排序；单项多选保持旧单素材签名，全默认保持历史版本复用。五页共享样式及词典、检索和创作相关资源缓存版本更新为 `20261019-recall-filters`。

## 验证

- 77 项 pytest 通过：检索和上传、召回执行、签名及缓存、创作 API 和工作区、渠道检索、国际化、分镜列与加载回归。新增验证覆盖三种查询的多素材并集、单素材、未知素材、空列表及标签组合，以及单项兼容、顺序和重复项签名。
- 新增 `tests/recall_filters_ui.cjs`：两个页面的文字／图片／视频界面，中文和英文，1440、1000、800、540、390、320px，共 72 个实际布局。检查字段尺寸、同行偏差不超过 1px、整页无横向溢出；图片和视频检索的上传区及文件框在相同语言和屏宽下位置与尺寸一致。
- 浏览器实际操作：素材多选、过滤、全选、刷新保留、清除、列表高度拖拽、查询请求携带多选值、分镜筛选保存和取消、文字召回结果约束，以及图片和视频文件上传后保存。模式及语言切换保留筛选值；无页面脚本错误。
- 原国际化浏览器回归通过：五页、动态编辑器、输入／文件／焦点／播放节点保留、延迟响应、持久化及跨标签页同步。
- 人工检查检索图片窄屏、分镜文字桌面和视频召回桌面截图。Ruff、JavaScript 语法及受影响文件 diff 空白检查通过。

计算样式记录及截图见 [artifacts/recall-filters](../artifacts/recall-filters/coverage.json)，测试日志保存在同目录。隔离库位于 `/tmp/mindex-recall-filters-20261019` 和 `/tmp/mindex-recall-i18n-20261019`；测试仅使用确定性颜色向量和本地模型替身，没有操作实际素材或外部模型。

## 限制及复现

本轮验证使用 Chromium 响应式视口，未验证其他浏览器及触屏 resize。72 个案例覆盖本次修改的正常编辑状态；未重新执行先前全页面错误／加载／空数据组合检查。

启动 `tests/serve_fixture.py` 的隔离库后，通过 `Pipeline` 添加至少三份素材并构建 `shot` 和 `moment` 索引；本轮增加了 `蓝绿素材.mp4`、`绿色素材.mp4` 两份颜色片段。浏览器脚本通过 `MINDEX_RECALL_URL` 指定本地端口，`MINDEX_PLAYWRIGHT_MODULE` 指定 Playwright 模块；视频上传样本默认来自上述隔离库。国际化回归需要单素材的独立库，使用 `MINDEX_I18N_TEST_URL` 指定地址。
