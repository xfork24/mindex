# Studio 分镜与版本工作台

入口 `/studio`。设计依据为 [STUDIO_UI_PLAN.md](../plans/STUDIO_UI_PLAN.md)。保留 Python、文件存储和原生前端；首次进入任务工作台时接入版本模型，原文件和执行历史保留。

## 工作区

任务标题可以独立保存，不改变方案、分镜或媒体版本。任务包含多个构建方案，可以新建、命名、复制和切换。方案分别保存分镜表、内容版本、阶段选择、人工素材范围及参数，共享任务内的产物历史。重新拆分使用新分镜身份，不影响其他方案。

创建任务只提交文案与“可用素材”多选（默认全选），不再提供高级选项：音轨、字幕、召回数量使用服务默认值（默认软字幕轨道），创建后在“方案参数”里调整。可用素材是任务级的召回硬上限：逐镜“文本与查询”里的素材范围只能在其中二次选择，两层取交集。全选等价于不限（记录为 `null`，此后新增素材自动可用），全不选会被拒绝并提示至少选择一个素材。所选 id 记在 `job.json` 的 `source_ids`，创建后只读，不进方案参数对话框；旧任务没有该字段即不限。图片与视频召回同样受此限制。分镜素材范围与任务范围没有交集时直接报错，不退化成全库。

任务 ID 与构建方案之间有只读的“任务元信息”折叠区，只展示创建后不可变的输入：创作文案（整行铺开，按原文分段换行，不截断）、创建时间、可用素材（`null` 显示为“不限（全部素材）”）。这些值取自 `job.json`，面板不提供任何写入路径；音轨、字幕、召回数量、音色等高级选项由方案参数独立展示并可动态调整，不在元信息中重复。

分镜矩阵的列依次为文本与查询、召回、配音、选片与对齐、分镜渲染。格内显示已选版本、摘要、最近执行结果和兼容性提示，详情展开后可浏览候选、试听、查看历史或选为构建输入。这两个历史操作互相独立；选择版本不会执行模型或渲染。矩阵支持横向滚动，固定分镜标识和表头，也可以整体折叠。下方依次为成片、产物与调试记录。

召回详情的“执行 / 复用”优先选择输入、检索设置及索引等匹配且文件完好的成功召回版本，没有时才重新检索；“强制重新生成”跳过复用，每次重新检索并新增版本。两者仅执行召回。“查看完整版本”集中展示完整的实际输入、参数、候选数据、依赖树及 candidates 文件下载；单元格详情不再重复下载入口和参数段落。

配音、选片与对齐、分镜渲染详情也统一通过“查看完整版本”下载文件及查看实际输入、参数和依赖树。配音和渲染详情保留内嵌播放器；选片详情保留窗口与音画试听，已保存选片版本的预览入口集中在完整版本中。

点击单元格会在该分镜下方展开整行详情，同格再次点击收起，同镜其他格切换详情；不同分镜可独立展开。文本、查询和预估时长水平编辑，保存只修改当前镜；移动、合并、插入和删除也在该镜详情内操作。未保存草稿按任务、方案和分镜保留，执行前需保存或取消。轮询保留未变化的详情和播放器。

文本与查询详情中的“召回设置”支持文字与人物、图片找视频、视频找相似，并可限定素材。文字模式可多选已登记人物，选择出镜或对白提及，以及同时出镜或任一人物。图片限 20MB，视频限 100MB、30 秒；上传后可预览，保存分镜后生效。每镜独立保存设置；合并保留上一镜设置，上一镜为默认文字时继承下一镜设置。人物候选显示身份、证据图及审核链接，覆盖不足时明确提示。文本与查询详情还提供“检索粒度”与“返回数量”下拉（选项与视频检索页一致）：默认“跟随方案”（粒度取服务配置、数量取方案参数的召回数量），选定后仅覆盖当前分镜的召回，格内摘要显示“召回覆盖”标记；四种召回模式均受其影响。

查询文件按 SHA-256 保存在任务的 `inputs/`，相同内容去重，纳入产物和任务 ZIP。执行前复验摘要，文件缺失或损坏会要求重新上传。更换召回方式、人物、素材或文件会使对应召回版本需要重建；改回旧设置可复用历史成功版本。召回同时绑定内容索引与人物发布记录，回退后使用对应组合。新增人物发布参数会使部署前的召回版本进行一次重建；全默认分镜设置保持旧查询 payload 不变。

“构建成片”位于“方案参数”右侧。方案栏下方的只读工作日志展示当前方案最近一次执行，并在运行时增量刷新；结束后保留日志。每个业务列头提供“全部重新生成”：文本与查询按原始文案重新拆分整份分镜，其他列仅强制执行本列当前所有分镜。缺少输入的镜头标为阻塞，其他独立镜头继续；不会自动执行其他阶段或合成成片。

## 版本与依赖

每次实际执行保存独立的不可变版本，包含阶段、分镜身份、成功或失败结果、输入版本、参数快照、文件路径及 SHA-256。成功后更新当前方案的对应选择；失败只新增记录，保留原有选择和全部下游产物。

兼容性按实际使用的内容和阶段参数检查：查询影响召回，旁白与声音影响配音，选片依赖其实际配音、召回版本及候选锚点。新人工窗口保存候选引用；仅旧式人工素材范围不依赖召回。分镜渲染绑定选片与音频版本、原片文件身份及处理参数。上游变化只展示具体冲突；构建时才决定复用和重建。

构建依赖为 `内容 → 召回 / 配音 → 选片 → 分镜渲染 → 成片合成`。分镜表另外记录身份、数量和顺序。每个新成片保存实际使用的完整依赖图及方案快照；依赖树可展开、查看节点详情，并可复制为新方案。

## 构建与人工控制

“构建成片”先显示复用、重建、阻塞和无需执行的清单，确认后执行。预检令牌绑定方案、输入版本与生效参数，提交时变化会要求重新预检。每格也支持单独执行或复用，强制重新生成是单独入口。

某节点失败后，其他独立镜头及分支继续执行，依赖失败节点的后续节点标为阻塞。必需依赖未齐时不合成新成片，已有成片始终可播放和下载。再次预检续建会复用输入指纹和文件哈希均匹配的成功版本。构建状态为 running/complete/partial/failed，节点另有 reused/blocked/skipped 状态。

逐镜选片按“选择召回候选 → 拖动定长窗口 → 保存当前窗口”操作。召回和选片详情分别提供候选预览、设为参考锚点与恢复自动选择；自动模式沿用综合评分，不固定使用首个候选。锚点按方案和分镜保存，绑定召回版本与候选 ID。选择只修改构建输入，保留已有选片与视频；更换锚点会移除此前确认范围。切换召回版本后，人工锚点来自其他版本时显示具体冲突，需重新选择候选或恢复自动模式。

“恢复自动选择”保存自动模式，从人工模式切换时清除此前人工范围，不立即选择或保存某个候选。打开选片窗口或执行选片时，才结合语义、实际成功配音时长及素材延长情况评分；窗口显示解析出的实际参考候选。无成功配音时等待配音完成。恢复自动模式不会改变已有选片与视频的历史依赖。

局部上下文为同一原片的前两镜、整个候选锚点组和后两镜；不足配音有效时长的两倍时，按前后两侧原有时长比例增加相邻镜头，直到总时长至少达到两倍；一侧无法延伸时由另一侧补足。隐藏区间、素材边界和断点均停止延伸。定长窗口使用当前成功配音的实际时长；明确设置速度时除以该速度，未指定时为原速。仍不足时禁用窗口与确认，不自动变速或冻结。无配音也能选择候选，窗口等待配音完成。

时间轴显示连续视频缩略图、镜头边界与锚点标记。可以整体拖动、点击定位、左右方向键逐帧微调，Shift 移动十帧，Home / End 到合法边界；缩放后支持横向滚动。窗口可以完全离开锚点。拖动只在本地定位画面；直接使用视频窗口内的播放键播放当前选区，到窗口结束自动暂停，从结尾再次播放会回到窗口起点。“保存当前窗口”无需先点预览，内部自动获取当前范围的校验令牌后保存；缺少配音、素材不足或正在执行时禁用，并显示具体状态。“试听配音与画面”是可选操作，生成当前范围与配音混合的音画预览，本身不保存选片。保存后创建新选片版本，保存真实候选、上下文、最终范围、实际范围和音频依赖。配音、速度、素材可见性或方案 revision 变化会使旧预览失效。草稿按任务、方案、分镜、候选、配音版本和速度隔离，切换详情保留有效位置。

选片详情的“按当前输入选片 / 复用”使用当前锚点或已保存范围，优先复用成功版本；“重新生成选片版本”跳过复用并新增版本。两者都不保存尚未提交的窗口草稿，也不自动渲染分镜或合成成片。

旧区间 API 与历史产物继续保留。缺少候选引用的旧人工版本展示原范围，重新调整前要求明确选择候选，不从范围内第一镜推断历史锚点。

方案参数包括当前配音服务的声音 ID、召回数量、原声混音及增益、字幕模式、配音速度和补齐策略；任务级素材范围不属于方案参数，创建后不可更改。自动选片的速度留空时自动选择；冻结策略保持原速配音；严格策略要求范围与配音时长匹配。人工定长窗口始终使用指定速度或原速。没有新增跨素材拼接、情感控制、版本删除或自动清理。

音色默认采用 `voice_mode=inherit, voice=null`，每次提交执行时读取当前配音服务的默认音色；切换模型或默认音色无需逐任务修改。只有明确选择“为本方案指定音色”时，才使用 `voice_mode=custom` 和指定的 `voice`。批次提交后使用当次配置快照，各配音产物保存实际音色和模型；历史文件与参数不随全局设置修改。新建方案默认跟随默认音色，复制方案保留明确的覆盖选择。

旧方案没有记录默认音色与人工覆盖的区别，现按跟随默认处理；旧值保留为 `legacy_voice` 参考，不再参与执行。读取时仅在内存中规范化，下一次受执行锁保护的写操作才保存；历史产物与成片快照不修改。若需要固定某个旧音色，可重新明确指定。

仍使用全局 `studio.lock` 串行执行。方案编辑、选择、删除任务、ZIP 导出与执行互斥，冲突返回 409。服务重启后的未完成构建保留历史并标为中断，可重新预检续建。

## 文件与迁移

```text
data/studio/<job_id>/
  job.json                  # 任务标题、原文及旧流程状态
  workspace.json            # schema=2：方案指针、版本索引、构建执行与节点结果
  builds/<build_id>/events.jsonl # 可增量读取的人类可读执行日志
  versions/<version_id>/
    version.json            # 不可变版本记录
    debug/*.json            # 请求、响应、ffmpeg 命令及错误诊断
    ...                     # 此版本的候选、音频、视频或成片
  migration-v2/             # 迁移前 job/storyboard/timeline/audio/checkpoints 快照
  attempts/...              # 原执行产物与历史，原样保留
  previews/...              # 由明确版本/参数生成的预览缓存
  exports/*.zip             # 导出包不递归包含导出包
```

迁移校验旧 manifest 的文件哈希，导入可验证的召回、配音、分镜视频及历史成片。无法证明输入关系和参数的旧版本标为“记录不完整”，不会按当前分镜猜测旧依赖，也不会自动视为可复用版本。旧成片仍可下载；依赖关系不完整时不能恢复为可验证方案。所有新版本均保存明确依赖。迁移是按任务进行的，打开前不会批量修改现有任务。

认证头、密钥和 URL 中的凭据经过诊断脱敏。原片不复制进任务目录；版本记录素材身份及文件指纹。产物下载 URL 指向确定版本文件，不依靠可变别名或缓存查询参数代表版本。

## 媒体与字幕

分镜渲染独立保存确定帧数的视频和处理后的 48kHz PCM 音频。帧数依据实际处理后采样数计算，保证在任意成片位置都能容纳完整配音。合成混选版本时，根据累计帧边界统一计算各镜的采样补齐和字幕时间，避免逐镜浮点累计或独立取整造成漂移。

定长窗口的字幕结束时间和分镜时长使用同一精确值，保留音频采样和变速带来的非整数毫秒时长；毫秒取整仅用于界面显示及字幕文件输出，不用于放宽事件的边界校验。

视频先裁到实际原片范围，再冻结末帧。音频支持变速、响度归一化及原声压低混音。成片发布前检查音视频轨道、字幕模式、时长和完整解码；失败保留已有成片。软字幕同时保存 MP4 mov_text、SRT 和 WebVTT；烧录字幕需要部署环境的 ffmpeg subtitles/libass 和可用中文字体。

技术对齐不保证叙事、人物或查询质量，仍需人工审阅。确定性测试音频也不代表真实发音质量。

## API（前缀 `/api/studio`）

| 方法与路径 | 语义 |
|---|---|
| POST /jobs | 创建任务，支持标题、原文和默认选项（`options.source_ids` 限定可用素材） |
| GET /jobs | 任务列表 |
| GET /jobs/{id}/workspace | 版本工作台详情；首次访问进行迁移 |
| PATCH /jobs/{id}/title | 独立编辑任务标题 |
| POST /jobs/{id}/plans | 新建、copy_from 复制方案或 from_final 恢复成片方案 |
| POST /jobs/{id}/plans/{plan}/activate | 切换方案，不执行任何阶段 |
| PATCH /jobs/{id}/plans/{plan} | 携 revision 保存名称、options 或完整 shots |
| POST /jobs/{id}/plans/{plan}/query-media | multipart file + kind=image/video；校验、去重上传并返回 media_id、预览 URL，201 |
| GET /jobs/{id}/versions?stage=tts&shot_id=... | 查询阶段历史版本 |
| GET /jobs/{id}/versions/{version} | 版本详情 |
| GET /jobs/{id}/versions/{version}/dependencies | 明确输入依赖图 |
| POST /jobs/{id}/plans/{plan}/select-version | revision、stage、shot_id、version_id；仅成功版本可选 |
| GET /jobs/{id}/plans/{plan}/preflight?force=false | 构建清单与确认 token |
| POST /jobs/{id}/plans/{plan}/build | 提交 token、force；后台执行，202 |
| POST /jobs/{id}/plans/{plan}/nodes | revision、stage、shot_id、inputs、force；明确输入版本，202 |
| POST /jobs/{id}/plans/{plan}/regenerate-column | revision、stage、inputs_by_shot；强制重跑一列，split 的输入表为空，其余绑定全部当前分镜输入，202 |
| GET /jobs/{id}/builds/{build}/logs?after=0 | 按 seq 增量读取执行日志，返回 next_seq、has_more；无日志的旧执行标记 legacy |
| GET /sources/{source}/shots | 按时间排列的镜头及可见性 |
| POST /jobs/{id}/plans/{plan}/anchor | revision、shot_id、mode=auto/manual；manual 还需 recall_version、candidate_id；只保存输入 |
| GET /jobs/{id}/plans/{plan}/shots/{shot}/selection-context | 实际锚点、候选引用、配音版本、合法范围、定长时长、帧步长、镜头边界及缓存视频/缩略图 |
| POST /jobs/{id}/plans/{plan}/range-preview | 新窗口：revision、shot_id、context_token、anchor_ref、tts_version、start，由服务器计算 end；旧 source_id、start、end、segment_ids 请求继续支持 |
| POST /jobs/{id}/plans/{plan}/range-confirm | 原预览请求及 preview_token；保存新选片版本 |
| GET /jobs/{id}/versions/{version}/preview | 对确定的选片或分镜视频版本预览 |
| GET /jobs/{id}/artifacts | 全部产物与诊断文件列表 |
| GET /jobs/{id}/artifacts/{path}?download=true | 确定路径的播放或下载，支持 Range |
| GET /jobs/{id}/archive | 空闲时导出任务 ZIP |
| DELETE /jobs/{id} | 删除整个任务，仍使用现有互斥限制 |

错误为 `{"detail": ...}`。已有旧任务的阶段 API 保留给尚未接入工作台的调用；迁移后的任务使用方案 API，旧阶段执行及 storyboard/timeline 编辑入口返回 409，防止可变别名覆盖版本工作台。旧任务详情、旧文件下载与历史 URL 仍保留。

工作台详情的 `tts_settings` 返回当前模型、默认音色、方案生效音色及音色模式。保存方案参数时，`voice_mode=inherit` 会清除 `voice`，`custom` 要求非空 `voice`；旧 API 调用显式提交非空 `voice` 且未指定模式时仍视为人工覆盖。

浏览器专用服务可通过 `uv run python tests/serve_fixture.py --data-dir <临时测试目录> --port 8001` 启动，勿将确定性颜色向量用于真实素材索引。

逐镜文本编辑器的召回设置支持素材范围多选、场景、人物情绪、景别和最短／最长时长；这些素材筛选也适用于图片及视频召回。素材列表带搜索过滤和右下角高度拖拽；不选素材时搜索全部库。任务限定了可用素材时，这里只列出范围内的素材。旧的单素材设置继续读取，保存新的多选时写入 `filters.source_ids`。素材顺序和重复项不影响召回版本复用，单项多选与旧单素材配置保持相同签名；全选时不写入筛选，签名保持默认，历史召回版本继续复用。

分镜工作台默认折叠所有行，左上角按钮可切换展开/折叠所有行。阶段列同时提供全部执行/复用和全部重新生成。文本与查询中的素材范围默认全选任务允许素材；演员和角色仅显示所选素材关联影片中的组合，切换素材时清除不再适用的人物。自动选片使用与定长窗口一致的默认范围，尾部不足时向前移动起点，保证可用范围内完整容纳配音。

创作任务默认使用软字幕轨道。任务元信息中的文案隐藏空白行，可用素材独占整行并逐项列出。分镜文案保留原文语言，LLM 召回查询词按对应文案生成 2–5 个空格分隔的中文词汇。召回候选图右上角标记当前自动选择或人工已选择的锚点。
