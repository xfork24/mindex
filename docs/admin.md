# 素材后台指南

后台地址 <http://127.0.0.1:8000/admin>。它**直接读 SQLite、不依赖活动索引或 GPU 服务**——素材切片完成即可管理，未嵌入也能播放/下载/编辑。

## 页面功能

- 按素材**显示名称或原文件名**搜索；分页每页 48 条（最大 100）。
- 查看镜头与精细片段：点击镜头查看其子片段，片段可返回并定位父镜头；显示时间顺序位置。
- 播放、下载 MP4（`download=true` 时按显示名+时间命名）；缩略图。
- 编辑显示名称、备注、收藏、隐藏；按可见性（visible/hidden/all）与收藏筛选。
- 镜头与精细片段的操作依次为“详情、备注、收藏、隐藏”。详情独立显示 ASR、字幕轨道、LLM 和人物处理信息；人物小节列出已处理/未处理的原片区间、已接受/待确认/已驳回证据数及关联人物。覆盖分为未处理、部分处理、处理完成；有覆盖但未识别出人物仍属于处理完成。
- 详情只读取已有数据及可缓存的字幕文本，无需在线模型或已发布索引，不启动 ASR、LLM 或人物推理。

## 素材组与音乐组

素材管理按「素材 → 音乐库 → 管理」排列。「管理」页 `/admin/groups` 分别管理素材组和音乐组，支持组名称、说明和成员分页，默认选中首组展示成员。添加区默认加载全部现有素材（音乐组加载全部曲目），复用检索页的可搜索多选列表，支持全选当前结果和批量添加或移除。素材与音乐详情中的「所属组」支持多选，同一条媒体可加入多个组；同类型组名称去除首尾空白后唯一。组没有子组，加入或移除只修改 SQLite 关系，不复制或移动文件。删除组也不删除媒体。

检索页（文字、图片、视频、找相似）与任务创建可选择素材组，筛选控件采用可搜索多选列表框；任务元信息只读展示素材范围，不提供范围或组的调整控件，分镜「文案与查询」只提供素材范围选择，不显示素材组筛选。组筛选排在素材范围前，创作任务的组筛选位于「可用素材」上方，选择组后联动缩小列表，取消组选择后恢复完整列表。控件采用紧凑横向布局，空间不足时自然换行。素材管理页「素材」Tab 左侧素材列表也提供同款组筛选，与查找、显示范围、收藏条件叠加，经 `GET /api/admin/sources` 的 `source_group_ids` 在服务端过滤。音乐库左侧曲目列表的组筛选同样采用可搜索多选列表框，与搜索、情绪条件叠加；分镜选曲与推荐也可选择音乐组。所有保留的组筛选都提供“全部选择”，且默认即为全选；全选（含默认与重置）表示不限，不写入筛选条件，也不在任务创建、选题档案中保存组 ID，仅部分选择时才保存实际组 ID 并与素材范围联动；该条目不用于详情归属编辑。多选组成员取并集，再与手动素材限制、任务范围及其他筛选取交集。所选组为空时无候选，不会扩大到全库。

每次检索、召回或推荐读取最新成员。相关召回签名包含组成员和有效状态；未引用该组的任务不受组变更影响。已保存的选片、曲目 ID 和构建产物保留原引用。删除被任务引用的组后，任务保留组 ID 并显示失效，后续召回要求在任务范围或分镜筛选中重新选择。

组接口前缀 `/api/admin`：

| 接口 | 说明 |
|---|---|
| `GET /groups?type=source\|music` | 列举组及成员数 |
| `POST /groups` | 创建：`type`、`name`、`description` |
| `GET /groups/{id}?page=1&page_size=48` | 组信息、成员数及分页成员 |
| `PATCH /groups/{id}` | 更新名称或说明，类型不可修改 |
| `DELETE /groups/{id}` | 删除组及关系，保留媒体 |
| `POST /groups/{id}/members` | `member_ids` 批量添加，自动去重且整批校验 |
| `POST /groups/{id}/members/remove` | `member_ids` 批量移除 |
| `PUT /group-memberships/source\|music/{member_id}` | `group_ids` 设置单项全部所属组 |
| `POST /groups/resolve` | `source_group_ids` 与 `source_ids` 的有效交集，空范围或失效引用返回 422 |

`GET /sources` 支持重复查询参数 `source_group_ids`；`GET /api/studio/music-library` 支持重复参数 `music_group_ids`，推荐请求体也支持 `music_group_ids`。任务创建的 `options.source_group_ids` 保存稳定组 ID；`GET/PUT /api/studio/jobs/{job_id}/material-scope` 查询或更新任务范围。未设置组字段的旧请求与旧任务保持原行为。

## 整理语义

- **改名**：显示名实时覆盖检索结果显示；**不修改**文件、稳定 ID 或已有嵌入（索引快照不含整理信息）。
- **隐藏**：立即退出检索召回——素材隐藏影响全部子片段，镜头隐藏影响其精细片段；**恢复上级时保留片段自身的隐藏状态**。选「已隐藏」或「全部」可找回内容。恢复不需要重建向量。
- **收藏**：仅筛选标记，**不影响相似度排名**。
- 点击“添加新素材”选择或拖入多个视频，顺序上传；逐个显示进度、登记结果及失败原因。单个失败不影响其他文件。
- 上传只登记原片；按内容哈希去重，重复文件定位已有素材，不覆盖结果。原文件名保存在 `sources/<sha256>/<原文件名>`，旧库路径继续有效。
- 素材默认每文件限额 20 GiB，可用 `source_upload_max_bytes` 调整；与检索查询视频的 100 MB 限额独立。空文件、无视频轨道、超限和中断会清理临时文件。
- 网页支持删除素材处理结果（保留原片）；暂不支持时间边界编辑。
- 整理数据存 SQLite 独立表（`source_curation`/`segment_curation`），旧库启动自动补表，旧素材默认未隐藏未收藏。

质量评测期间不要修改整理状态——e2e 实验把 curation 哈希冻结进 `run.json`，变化会使后续 phase 拒绝执行。

## 管理 API

前缀 `/api/admin`，完整定义见 `/docs`。

| 接口 | 说明 |
|---|---|
| `GET /sources?q=&visibility=visible\|hidden\|all&favorite_only=false&page=1&page_size=48` | 名称搜索（原名+显示名，不区分大小写子串）、筛选、分页 |
| `GET /sources/{id}` | 媒体信息、镜头/片段计数、缺失文件数、最近 5 条处理记录 |
| `GET /sources/{id}?detail=summary` | 轻量摘要：仅基础信息、片段数量与 GPU 锁配置，供详情页首屏并发加载；完整详情接口保持兼容 |
| `POST /sources/upload` | multipart 单文件 `file`；返回 `source_id` 与 `duplicate`；前端顺序提交批量文件 |
| `POST /sources/{id}/shots` | 分镜检测及切片/修复，`{"publish":true}`，返回持久任务（202） |
| `POST /sources/{id}/subtitles` | multipart `file` 上传外部文本字幕，返回 `id/name/format/utterances`；上传只登记，未应用对白 |
| `POST /sources/{id}/dialogue` | `method:auto\|subtitle\|asr`、`subtitle_stream` 或 `subtitle_file`、`publish`、`workers`；上传文件须使用 `subtitle` 并指定文件 `id`，不能同时选内嵌轨道 |
| `POST /sources/{id}/analysis` | 分镜完成后启动 LLM 分析，`{"publish":true}` |
| `POST /sources/{id}/publish` | 独立更新检索，`{"work":"shots\|dialogue\|analysis\|persons","scope":"shot_moment\|scene"}`；shot_moment 更新 moment+shot、scene 只更新已有场景（scene 仅限分镜/对白/分析，persons 仅接受缺省 shot_moment） |
| `GET /source-tasks/{task_id}` / `POST /source-tasks/{task_id}/retry` | 分镜、分析、检索更新任务查询与重试（可重试 failed、interrupted、cancelled） |
| `POST /source-tasks/{task_id}/cancel` | 取消排队中或运行中的素材任务；其他状态 409 |
| `GET /dialogue-tasks/{task_id}` / `POST /dialogue-tasks/{task_id}/retry` | 对白任务查询与重试 |
| `POST /dialogue-tasks/{task_id}/cancel` | 取消排队中或运行中的对白任务；其他状态 409 |
| `GET /sources/{id}/report` | 素材报告（线程池生成）：计划镜头数、时长统计、缺失文件明细、布局是否与当前配置一致、最近运行记录 |
| `GET /sources/{id}/frame?t=<秒>&width=768` | 该时间点的 JPEG 画面，`width` 16–1024（默认 768）；`t` 非有限数或不在 `[0, 素材时长]` 返回 422，素材不存在 404；带基于镜头文件修订、`t`、`width` 的 ETag（`If-None-Match` 命中返回 304，`Cache-Control: private, max-age=3600`），进程内最多 4 个并发抽帧 |
| `GET /sources/{id}/person-setup?work_id=` | 只读检查作品、演员、角色与参考图，缺失时提供人物库入口 |
| `PATCH /sources/{id}` | 修改整理字段 |
| `GET /sources/{id}/segments?kind=shot\|moment&parent_id=&visibility=&favorite_only=&page=&page_size=` | 片段列表；`parent_id` 仅用于 shot→moment |
| `GET /segments/{id}` | 片段详情：归属、时间位置、父子、隐藏继承 |
| `GET /segments/{id}/details` | ASR、字幕轨道、LLM 与人物处理覆盖/证据统计，按当前片段时间范围裁切 |
| `PATCH /segments/{id}` | 修改整理字段 |
| `GET /segments/{id}/media[?download=true]` | 未嵌入片段的播放/下载，支持 Range/HEAD |
| `GET /segments/{id}/thumbnail` | 缩略图 |

PATCH 请求体（`extra="forbid"`，未知字段 422）：

```json
{"display_name": "新的显示名", "notes": "备注", "favorite": true, "hidden": false}
```

- `display_name` 最长 200 字符，**空字符串恢复默认名**（存 NULL）；`notes` 最长 4000。
- 至少提供一个字段；素材不存在返回 404；文件缺失的媒体返回 404 并提示用 `split` 修复。

示例：

```bash
curl -s 'http://127.0.0.1:8000/api/admin/sources?q=trailer&page_size=10'
curl -s -X PATCH http://127.0.0.1:8000/api/admin/sources/SOURCE_ID \
  -H 'Content-Type: application/json' -d '{"display_name": "预告片", "favorite": true}'
```

## 与检索索引的关系

检索 API（`/api/segments/{id}` 等）读的是**活动索引的冻结快照**；后台 API 读的是**当前素材库**。两者通过稳定片段 ID 关联；后台的改名/隐藏在检索结果上以叠加层生效（`Library.decorate`），不触碰向量。

## 四项处理工作台

素材详情保留原有字段，并新增 `work.shots/dialogue/analysis/persons`：真实处理状态、结果摘要、最近处理任务、独立发布任务、进度、发布结果、检索覆盖与版本是否当前，以及启动条件。已有完成结果与最近失败任务分别展示，查看详情不启动任何模型。

桌面左侧查找素材面板从当前位置延伸至视口底部，页面下滚后固定在视口顶部并占满高度；窗口缩放、提示文字和语言切换时自动重新计算。素材列表在搜索、筛选、分页和帮助文字之间独立滚动，到达列表边缘不会带动右侧内容；手机采用单列，素材列表最高占半个视口。

| 工作 | 操作与结果 |
|---|---|
| 分镜处理 | 登记后可启动；显示镜头、精细片段和缺失文件数。完成后可查看镜头，也可点击“拆分镜”检查与修复；旧素材修复沿用已有片段边界，不因设置变化重切。新素材冻结登记时的切分配置。 |
| 对白处理 | 自动优先完整文本字幕，无法使用则回退 ASR；手动字幕可选择内嵌文本轨道或上传字幕文件，点击“开始处理”后应用，提取失败直接报错；内嵌空字幕显示无对白。手动 ASR 跳过字幕。显示实际来源、轨道/文件/模型、对白条数、有对白片段数和检索覆盖。无音轨、空对白分别展示。 |
| LLM 分析 | 分镜完成后可启动；有对白则使用，没有对白仍分析画面。显示已分析/应分析片段、场景数、敏感跳过数及待分析数；场景分组完成后，总数包含已经排好但尚未生成媒体的场景，在镜头详情中查看分析。 |
| 人物处理 | 分镜完成后配置关联作品，预检演员、角色和参考图，默认处理整部素材；显示完整分镜覆盖、关联人物和已接受/待确认/已排除分镜数，入口跳转人物核对。处理完成不表示所有身份均已人工确认。 |

四项工作分别点击启动，默认勾选“完成后更新检索”，也可关闭后手动更新。无“一键全部处理”。设置页“强加 GPU 锁”默认关闭，允许不同素材和不同类型的处理并行；同一素材同类工作不重复启动，正在处理的素材不能删除，其他素材可删除。开启后任务和 CLI 通过 `pipeline.lock` 全局互斥，忙时返回 409。锁策略在启动及重试时读取当前设置；运行中的任务继续持有已取得的锁。模型配置仍冻结，重启后仅无人持锁的任务标记中断，不自动重发远程请求，由用户重试续接检查点。检索写入单独串行，避免增量发布丢失其他素材或渠道。

处理结果在发布前保存。处理成功而发布失败时仍显示处理完成，单独记录发布错误；点击“更新shot/moment嵌入”“更新scene场景嵌入”或重试原任务只执行发布，两个按钮分别覆盖 moment+shot 与已有 scene。增量发布保留其他素材、渠道和既有检索粒度。人物发布复用 `/api/persons` 机制；无内容索引或素材尚未纳入内容索引时先建立已完成的内容渠道。

四项能力的处理任务与检索更新任务统一显示状态、当前阶段、真实完成数/总数和进度条，每 2 秒轮询。分镜切分按镜头、修复按片段；对白 ASR 按30秒音频块，字幕按文件或轨道；LLM 依次按片段分析、场景分组、场景分析计数；人物提取与匹配按镜头。阶段切换后分母随当前阶段变化。检测分镜、准备数据或等待检索写入锁时总数尚未知，显示阶段及不定进度条，不估算百分比。

自动“完成后更新检索”保留处理完成的进度，另列检索更新的状态与进度；分镜、对白与分析完成后会各创建 shot/moment 与 scene（已有场景时）两个独立发布子任务，独立更新检索使用相同显示，避免重复展示较早的自动发布。分镜、对白与分析渠道每完成一个片段就保存嵌入进度，如“运行中 · 嵌入片段 15/405 个片段”，随后显示索引检查和发布阶段。进度只统计当前素材所更新渠道的片段，长分镜的全部窗口完成后才计为一个完成片段；其他素材不计入分母。人物检索发布已有资料、出镜证据和覆盖快照，按当前素材去重后的镜头数显示准备与发布完成，不重复提取特征。重试从已保存的完整片段检查点开始计数，刷新页面可继续查看。上方“检索”覆盖表示已经发布的结果，发布完成前保持原值。

排队中或运行中的处理任务与检索更新任务各显示一个“取消”按钮（自动发布阶段指向处理任务本身，独立发布任务是素材任务）。排队中的任务立即变为“已取消”；运行中的任务在下一次上报进度时停止，等待 GPU 准入的发布任务在等待期间停止，期间按钮显示“正在取消…”。停止后任务状态为“已取消”（错误文本“已取消”），释放全部锁，已保存的检查点保留；“已取消”与失败、中断的任务一样显示“重试”，从断点继续。取消标记同时写入进程内事件与 `data_dir/locks/cancel/<任务 ID>` 哨兵文件，跨进程生效。取消处理任务不会连带取消已链式创建的发布子任务；发布任务中途取消时活动索引不变，正在构建的索引版本保持可续建。人物库页面的人物任务有同样的取消与重试按钮（`/api/persons/tasks/{id}/cancel`）。

智能助手的 `library` 领域可以浏览素材与片段、读取素材报告、修改整理信息、发起/查询/重试/取消处理任务、上传素材与字幕（见 [智能助手](agent.md#library)）；不提供删除素材。助手的改动会以 `library` 领域发布到改动通道，但本页目前没有监听该事件：助手修改整理信息或登记素材后需要刷新页面（或重新打开素材）才能看到，已打开素材的运行中任务仍按 2 秒轮询更新。

LLM 分析遇到无效 JSON、字段类型或必填字段校验失败（例如 `scene` 返回字符串）、无效场景分组、空正文、聊天格式错误或 HTTP 500 时默认自动再试 5 次，间隔为 1、2、4、8、8 秒；分镜分析、场景分析和场景分组共用这项规则，每次请求的各类无效响应合计消耗同一重试次数。设置页的多模态理解档案可调整“无效响应自动重试次数”（0–20）。字段或分组校验失败后，下次请求会附带字段路径、期望类型或违反的分组约束，要求重新输出完整 JSON。重试耗尽后才记录任务失败，已完成片段保留，手动重试继续检查点；运行中的任务沿用启动时冻结的次数。身份、鉴权和参数错误不会被这项重试覆盖。

模型明确拒绝内容时（如智谱400错误码1301或“不安全或敏感内容”，聊天响应的 `content_filter`/`sensitive` 结束原因或 `refusal`），保存该片段为 `skipped` 并继续处理后续片段。不会通过改写提示词、换抽帧或增加 token 重试拒绝内容。相同时间范围及已拒绝范围内的子片段复用跳过检查点；场景输入排除与拒绝范围相交的片段，场景不会跨过该时间缺口。场景分析被拒绝时也继续后续场景；分组批次被拒绝则保存空分组检查点，继续下一批。工作台显示敏感片段跳过数，详情显示拒绝原因；跳过片段不生成或发布 LLM 分析文本，视觉/对白渠道按各自流程保留。普通400参数错误、401鉴权、403权限错误仍使任务失败；仅明确内容拒绝可跳过。

分析任务“重试”使用启动时冻结的模型配置，同模型已完成和已跳过片段复用检查点；界面从头检查时不会重复请求已完成片段。设置页换模型后点击“分析场景”会创建新任务，缓存按模型隔离，重新分析片段并保留旧结果。目前不支持更换模型后只从旧任务中断处分析剩余片段；调整 token 预算、重试次数、超时或思考模式不改变缓存身份，新任务可复用同模型结果。

无效 JSON、字段或场景分组校验失败、空正文、输出截断或聊天响应格式错误时，后端 WARNING 日志会打印该次完整模型响应 JSON（含正文、厂商返回的推理字段和结束原因），标明模型与当前 `max_tokens`，以“—— 模型返回结束 ——”结尾；最后一次失败也会打印。不截断响应，不输出请求图片、提示词或鉴权头。

LLM 提示词要求正文仅包含最终 JSON：片段描述保持1–2句、数组只保留有依据的短语，空字段可省略；除 `description` 外的字段即使只有一项也必须是字符串数组，例如 `"scene":["夜间城市滨水区"]`，不能用字符串、对象或 `null` 代替。提示词提供格式示例并要求输出前逐项检查类型。场景分组输入逐项标明 `index`，提示词注明本批片段总数与索引范围；模型只返回场景起始索引 `scene_starts`（例如 `{"scene_starts":[0,2,7]}`），首项为0，其余严格递增且在范围内。程序按边界展开完整连续分组，末组自动覆盖至本批最后一个片段，避免模型逐项枚举时遗漏尾部。仍兼容严格有效的旧 `groups` 响应；漏项、重复、越界会给出具体索引反馈，禁止静默修补旧响应。禁止附加分组说明或方案比较。10–30秒为分组时长偏好，语义边界和短转场可不足10秒，避免为凑时长合并无关场景。厂商独立的 `reasoning_content` 不参与 JSON 解析，提示词不能保证关闭厂商内部推理；已完成的注释和检查点继续兼容。

默认 `thinking_mode:auto` 使用厂商支持的控制参数：GLM-5.3 / MiniMax-M3.1 强制思考模型使用 `reasoning_effort:low`，支持关闭的 GLM、MiniMax-M3 和本地 llama.cpp 则关闭思考。智谱文本场景分组及本地服务使用 JSON 输出模式；未知自定义服务不发送猜测的厂商字段。场景分组每批最多45秒或32个片段，历史描述在输入中压缩为160字和最多3个场景标签，已成功批次保存检查点，后续失败重试不重复调用。相同时间边界的分镜和精细片段仍复用注释。后端逐次记录请求耗时和输入、输出、思考 token，可比较实际优化效果。设置页的思考策略影响新任务；旧任务未存策略时使用 auto，已完成注释不重跑。

厂商依据：[GLM 思考模式](https://docs.bigmodel.cn/cn/guide/capabilities/thinking-mode)、[GLM 对话补全](https://docs.bigmodel.cn/api-reference/模型-api/对话补全)、[MiniMax Chat Completions](https://platform.minimax.io/docs/api-reference/text-chat-openai)。GLM-5.3 和 MiniMax-M3.1 不能关闭思考，使用 low；MiniMax 的 `reasoning_split` 仅分离输出，不能减少思考。

片段分析达到 `N/N` 后还需场景分组和场景分析；工作台分别显示这些阶段。`finish_reason=length` 表示输出预算耗尽，推理模型可能仅返回推理内容而无 JSON 正文。分镜分析、场景分组和场景分析统一从 12768 输出 token 开始；每次可重试的无效响应后翻倍：12768、25536、51072、102144，默认上限 131072（后续重试保持此上限）。预算含模型推理 token。即使正文恰好能解析为 JSON，只要响应标记截断也不接受。设置页多模态理解档案可调整“首次请求输出 token 预算”和“重试输出 token 上限”；首次预算不超过上限，上限需符合厂商实际支持范围。更新代码后重启后端，旧任务未保存的字段使用新默认值；已冻结的自定义设置仍保留。若旧任务已冻结 16384 上限，可用“分析场景”启动使用当前配置的新任务，复用已完成片段注释。重试次数及输出预算不改变分析缓存身份。

WeMM 按配置帧率采样视频。默认 4 fps 时，极短分镜可能因 FFmpeg 末尾取整而生成不含视频轨道的 MP4，服务会报 `ffprobe failed on buffer` / `Failed to load image or audio file`。客户端会检查采样结果，仅对这种极短空样本使用保帧兜底，并在请求前再次验证；已成功样本保持原有编码。更新代码后重启网页后端，确认 `bash scripts/run-wemm.sh` 启动的服务已就绪，再点击“更新shot/moment嵌入”即可复用已保存的嵌入检查点。无需重新切分或删除旧索引；切分完成并不表示嵌入及检索发布完成。另注意：现存六条兼容性基线原视频在当前 FFmpeg 环境下的预处理哈希与历史保存值不同（历史输入重现已有差异，来源未定），重新执行模型兼容性 smoke 时仍应遵守现有严格门槛，不能以采样修复为由放宽。

对白 API 旧调用与 CLI 保持兼容：未传 `method` 默认 `auto`，旧 `subtitle_stream` 在自动方式中仍可回退；仅 `method:subtitle` 保证严格字幕。CLI 可用 `mindex register 视频...` 只登记素材，`mindex enrich-dialogue SOURCE --method asr --no-publish` 单独处理对白。

选择“字幕轨道”后可上传 SRT、ASS、SSA、VTT、文本 SUB、SMI、SAMI（每文件最多20 MiB）；支持 UTF-8、带 BOM 的 UTF-16、GB18030 和 Big5 中文编码。上传成功自动选中，刷新后可继续选择；上传期间禁用开始按钮。文件按素材和内容摘要保存，开始与重试校验摘要；上传新文件不会改变已有对白，直到点击处理。字幕按原视频时间轴提取，移除样式标签，裁切至素材时长；MicroDVD SUB 使用文件内帧率，缺省沿用素材帧率。无有效对白、无有效时间戳、超出全片范围或位图字幕上传报错；不转用 ASR。处理后的文件名和对白显示在工作台及镜头详情，检索更新沿用已有发布流程；删除素材同时清理上传字幕。

工程验收时以隔离素材完成上传、四项任务、发布、检索、详情和浏览器桌面/窄屏测试。工程测试模型仅验证链路，不代表真实模型质量。

## 操作反馈位置

素材管理、人物库、设置、检索与创作页面的通用操作提示显示在当前操作区域，以单行替换上一条提示，完整信息可悬停查看。弹窗内错误留在弹窗；关闭后反馈回到所属区域。已有任务日志或人物发布状态区只在该区显示，不再同步到页面顶部。

素材组和音乐组均提供系统默认的“未分类”组：它自动包含未加入任何普通组的成员，导入、加入普通组、移除最后一个归属或删除普通组后即时更新。该组可用于检索和任务范围，支持成员分页查看；名称和成员由系统管理，不能手动编辑或删除。其稳定 ID 分别为 `ungrouped-source` 与 `ungrouped-music`。备份恢复后按恢复库的实际归属自动计算成员，不复制媒体文件。旧版同名自定义组迁移为“未分类（自定义）”，保留原 ID、成员及任务引用。

检索页和任务创建表单随组目录预载素材组成员，切换组时在浏览器内取并集，不逐次请求范围解析。目录在同页短暂复用并合并在途请求；组变更通知立即使缓存失效，返回页面时重新校验。手动刷新读取新目录，空组仍显示空素材范围。`GET /api/admin/groups?type=source&include_members=true` 可返回各组的 `member_ids`（含动态未分类组）；默认响应仍只含组信息和成员数量。

页面字段按显示内容决定宽度，同组控件横向排列并随面板宽度自然换行。多选列表按最长选项测量宽度，过长时以面板宽度为上限并在列表内部横向滚动，选项文字不拆行；搜索、重载和语言切换后重新计算，不改变选中值。创作工作台的文案与查询编辑区按行分配全部水平空间：旁白等正文、召回设置、素材与人物范围、场景等条件保持同行；AI 视频的提示词、反向提示词、种子同行，第三方工具的图片与视频上传同行。窄面板在各行内部横向滚动。

## 历史分析的英文补全

素材详情和检索详情中的分析随界面语言切换。旧结果缺少英文，或英文部分夹带中文时，可以运行：

```bash
uv run python scripts/repair-analysis-english.py --check
uv run python scripts/repair-analysis-english.py --workers 2
```

脚本扫描全部素材的最新分析及生效索引，优先复用已有精确对照，再用当前分析模型翻译缺失内容。译文保存在数据目录的 `analysis-translations.en.json`，原始分析、中文显示和已发布快照不变，无须重建向量索引。脚本支持断点续跑并在 `reports/analysis-english-repair.json` 写入剩余项；`--include-history` 可扩展到全部历史检查点和索引，`--profiles ID ...` 可指定本次翻译使用的分析模型档案，均不切换激活配置。API 仅附带本次响应涉及的英文译文，前端只在分析专用显示器中使用，不翻译用户标题或字幕原文。

## 素材处理的复用规则

UI、REST 和未带 `--force` 的 CLI 操作默认续跑，复用依据是原片内容、实际时间范围和处理输入。任务 ID、模型配置档案 ID、镜头 ID 或缓存目录变化本身不要求重新计算。只有缺少可用结果、产物损坏或必要输入变化时才补算。

| 操作 | 默认复用与失效边界 |
| --- | --- |
| 分镜、切片、缩略图 | 复用已保存的分镜计划、实际区间、有效媒体与缩略图，只修复缺失或空文件；切分布局变化仍须遵守新数据目录约束。 |
| LLM 分析与场景 | 复用相同原片区间的完成结果，保留真实模型来源；相同场景区间沿用已有 ID，已完成分组批次可跨配置档案续跑。当前场景按最新计划统计和发布，历史代次不叠加到当前任务。 |
| 字幕与 ASR | 相同字幕输入或已有完整对白直接复用；中断分块按原片区间和上下文范围检查，配置变化后仍复用有效分块。跨模型续跑逐块保留实际来源；原始转写和兼容的对齐检查点也可复用。显式更换字幕轨道或字幕文件会采用对应输入。 |
| 人物处理 | 相同原片区间、实际特征空间和采样间隔可复用特征，不因镜头 ID 或布局标识变化重新提取。采样范围、采样规则或真实特征空间改变时重新提取；参考图、规则及人工审核变化只更新必要的匹配结果。部分镜头范围按实际切片偏移采样。 |
| 索引发布 | 按实际视频区间或文本、嵌入空间和预处理身份复用向量。完整就绪版本不重复写入向量；成员或元数据变化时，新版本复制缓存向量。依赖文件与向量一致性仍需校验，同一素材的字幕依赖在每次校验中只检查一次。日志分别报告缓存复用和模型新生成数量。 |

`mindex analyze --force`、`mindex transcribe --force` 和 `mindex enrich-dialogue --force` 可显式忽略相应分析或转写检查点。UI 和 REST 任务参数不接受 `force`。强制重算仍保留已发布索引的不可变快照，后续发布采用实际可复用的向量，不跨不兼容的模型空间混用。

缓存发布只扫描需要的向量键，找到后停止向旧版本回溯；元数据按批提交，提交后才报告完成。
