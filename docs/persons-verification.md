## 2026-10-17 第二轮调整：导入优先与模糊召回

- 演员表导入移至人物库第一分区并作为默认入口；确认导入是演员/角色的主要创建方式——同名演员与同作品同名角色自动复用（姓名或外文名别名精确匹配），不存在的自动创建；导入作品可下拉选择或直接填写新作品名创建，不强制先手动登记。
- Cast 条目移除阶段名/年龄/造型/服装字段；同一人物的不同时期（如老年叶淑柔）直接写成完整角色名。人物库仍保留阶段实体（用于参考图配对与外观样本限定），但演员表不再创建阶段。旧草稿加载时自动清理已移除字段。
- 角色名后缀模糊召回：`resolve_names` 对角色做显著后缀匹配（后缀长度至少为名长一半），输入“叶淑柔”联合召回“老年叶淑柔”等变体；变体构成一个联合组，组内任一出镜即算，不视为歧义、不影响多人物 `all` 关系的同时出镜判定；输入完整名时最长名优先只召回该角色；仅长名角色登记时基础名仍可召回。显式 `person_ids` 选择保持精确语义。
- `resolve_names` 返回值扩展为四元组（新增变体组），`overlaps_for` 接受 id 或 id 组列表；检索出镜过滤改用变体组。
- 新增 `test_role_suffix_fuzzy_recall_variants_union_not_ambiguity`（联合召回、最长名优先、仅长名登记、跨身份歧义仍报错）并重写演员表导入测试（自动复用演员、同作品同名角色复用、`老年叶淑柔` 作为角色名创建）。
- 演员表确认的前置校验：客户端在保存/确认前校验作品已选、条目演员名或关联演员存在、照片框已勾选单人确认；服务端对空 `work_id` 返回明确的“请选择导入作品”。
