- 探测请求、响应与短句 WAV 保存于 `data/studio-verification/20261014-tts/`；未注册任何参考声音，未修改正式后续任务或 TTS 配置。

[Qwen 官方模型说明](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice)和[运行项目 README](https://github.com/ServeurpersoCom/qwentts.cpp#quick-start)将预置音色归于 CustomVoice，Base 用于参考音频克隆；GGUF 模型卡的用途表与它们不一致，部署兼容性以实际接口和源码为准。

CustomVoice 预置名称为 `vivian`、`serena`、`uncle_fu`、`dylan`（北京话）、`eric`（四川话）、`ryan`、`aiden`、`ono_anna`、`sohee`。选择预置音色需要部署 `qwen-talker-1.7b-customvoice-Q8_0.gguf`；保留 Base 则可用参考 WAV 及文本，通过 `POST /v1/audio/voices` 注册自定义声音。注册实现为进程内存表，重启后需重注册，参考音频与身份不能只记录声音名称（见[服务源码](https://github.com/ServeurpersoCom/qwentts.cpp/blob/master/tools/tts-server.cpp)）。

以上为首次 Base 部署的探测记录，不将“默认请求可返回 WAV”计为完整 TTS 验收。既有任务创建时固化了 `voice=Cherry`，后续接入有效声音时还须处理任务声音设置，不能只改全局配置后直接重试。
